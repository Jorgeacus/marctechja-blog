## Estrutura do Ebook

### Parte 1 — Primeiros Passos
Instalação do Hermes Agent em macOS, Linux e Windows. Configuração inicial, primeiros comandos, compreensão do terminal e interface de linha de comandos. Verificação da instalação.

### Parte 2 — Configuração de Providers
Configuração de múltiplos providers de IA: OpenAI (GPT-4o, GPT-4o-mini), Anthropic (Claude), Google Gemini, DeepSeek, modelos locais via Ollama (Llama 3.1, Phi-4-mini, Hermes específico). Definição de provider padrão e fallbacks.

### Parte 3 — Comandos Essenciais
Comandos fundamentais do Hermes Agent: chat interativo, execução de tarefas, gestão de skills, configuração de agentes, parâmetros de temperatura e contexto.

### Parte 4 — Criação de Skills
Criação de skills personalizadas em YAML e Python. Estrutura de uma skill, parâmetros, steps, outputs. Skills de comando, ferramenta, fluxo e conhecimento. Diretório de skills (~/.hermes/skills/).

### Parte 5 — Automações para Desenvolvimento
Automação de code review, geração de documentação, análise de código, testes automatizados, integração com GitHub/GitLab. Skills para programadores.

### Parte 6 — Automações Empresariais
Automação de atendimento ao cliente, análise de dados (CSV, Excel), geração de relatórios, integração com CRMs, gestão de projetos (Trello, Notion, Asana).

### Parte 7 — Equipas de Agentes
Criação de múltiplos agentes a colaborar. Comunicação entre agentes, delegação de tarefas, agentes especializados por função. Exemplos práticos.

### Parte 8 — Segurança e Boas Práticas
Gestão de chaves de API, permissões de skills, isolamento de agentes, logging e monitorização, boas práticas de deploy. Prevenção de prompt injection.

### Parte 9 — Deploy em Produção
Publicação de agentes como serviços, integração com APIs REST, webhooks, deploy em servidores. Docker, systemd, scaling.

### Parte 10 — Comunidade e Extensões
Ecossistema de extensões da comunidade, contribuição para o projeto open-source, recursos adicionais, fóruns, GitHub Issues.
