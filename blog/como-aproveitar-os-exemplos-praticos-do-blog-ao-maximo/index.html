Como Aproveitar os Exemplos Práticos do Blog ao Máximo

📅 13 Aug 2026 📖 5 min de leitura 🏷️ Guias ✍️ Marcus

Já reparaste que em quase todos os artigos deste blog há blocos de código prontos a copiar? Quero ser 100% honesto contigo: eles não são pseudocódigo nem exemplos de fantasia — são comandos e ficheiros reais, com a mesma sintaxe do Hermes Agent que tens (ou vais ter) instalado na tua máquina. Neste guia, explicamos-te o que precisas para os aproveitar ao máximo, sem frustrações.

O que tens de ter antes de começar

Um bloco de código só corre "como está" se estiverem reunidos três pré-requisitos. Vamos vê-los um a um.

  • Hermes Agent instalado: todos os comandos usam a CLI real do Hermes. Sem ele, não há nada para executar.
  • Um provider de IA configurado: o agente precisa de um modelo para interpretar e gerar conteúdo (OpenAI, Gemini, DeepSeek ou um modelo local via Ollama).
  • Credenciais dos canais (só nos tutoriais de WhatsApp/Telegram): estes códigos ligam-se a serviços externos e exigem tokens criados por ti.

Passo 1: instala o Hermes Agent (corrige o sistema operativo)

A instalação é oficial e muda apenas conforme o teu sistema operativo:

# macOS e Linux — instalador oficial
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

O que este código faz: o instalador descarrega a CLI do Hermes, coloca-a no teu PATH e prepara tudo para o primeiro uso. Não uses comandos de instalação que não sejam estes dois — são os únicos oficiais.

Depois de instalado, começa por configurar o teu provider de IA:

hermes setup

O que este código faz: abre o assistente interativo que cria a estrutura em ~/.hermes/ e te pede a chave de API do modelo que queres usar. Os teus dados de acesso ficam guardados fora do controlo de versões.

Passo 2: copia e cola sem medo (o verdadeiro segredo)

Os exemplos de skill nos artigos são ficheiros SKILL.md: um formato em Markdown, com um cabeçalho (frontmatter) e instruções em texto. O Hermes lê este ficheiro e passa a saber exatamente o que fazer quando ativas a skill no chat. Copia o conteúdo tal-qual e guarda-o em:

~/.hermes/skills/nome-da-skill/SKILL.md

Depois, usa-a assim (funciona igual em macOS, Linux e Windows):

hermes skills list                    # confirma que a skill é visível
hermes chat -s nome-da-skill "pede o que quiseres"

O que estes comandos fazem: o primeiro lista as skills instaladas e o segundo abre uma conversa com o agente já com essa skill carregada. Não há hermes run nem ficheiros .yaml com passos fixos — isso é a sintaxe antiga e não funciona. Tudo o que aparece nos artigos serve com os comandos reais aqui mostrados.

Passo 3: cria as tuas credenciais (só para WhatsApp e Telegram)

Os tutoriais de automação de mensagens usam o gateway de mensagens do Hermes. Estes são os únicos blocos que precisam de dados que só tu podes criar:

  • Telegram: fala com o @BotFather para criares um bot e receberes um token.
  • WhatsApp: regista-te no WhatsApp Cloud API da Meta para obteres o token e o Phone Number ID.

Com as credenciais na mão, colocas os dados no ~/.hermes/.env e ligas o canal:

hermes gateway setup

O que este código faz: regista o canal de mensagens que escolheste e associa a tua conta. Quando estiver ligado, os exemplos de agendamento com hermes cron create --deliver whatsapp (ou --deliver telegram) funcionam na hora.

As poucas diferenças entre sistemas (macro)

Quase tudo funciona igual nos três sistemas. As únicas adaptações, prática e esperada, são:

  • Comando de instalação: install.sh no macOS/Linux, install.ps1 no Windows.
  • Onde fica a config: ~/.hermes/ (macOS/Linux) ou %USERPROFILE%\.hermes\ (Windows).
  • Ferramentas de sistema em skills avançadas: se um exemplo invocar um comando de terminal específico, adapta-o ao teu sistema — exatamente como adaptarias qualquer script.

Fluxo de trabalho recomendado

Para tirares o máximo partido dos tutoriais, segue esta ordem — evita surpresas e ganhas confiança à medida que avanças:

  1. Instala o Hermes com o comando oficial do teu sistema e corre hermes setup para ligares o teu modelo de IA.
  2. Testa um comando simples num chat antes de tocar em skills ou canais: hermes chat -q "Olá, apresenta-te".
  3. Cria a tua primeira skill copiando o exemplo SKILL.md do artigo e confirma-a com hermes skills list.
  4. Ativa a skill no chat com hermes chat -s nome-da-skill e faz um pedido pequeno para validar o comportamento.
  5. Só depois liga o Telegram ou o WhatsApp, cria as credenciais e experimenta os agendamentos com o cron.

Este percurso em camadas permite isolar cada falha: se algo não correr, o problema está quase sempre no passo em que estás, e não no exemplo em si.

Perguntas frequentes

Preciso de saber programar para usar estes exemplos?

Não. Os blocos são comandos de terminal e ficheiros de texto simples. Saber o essencial de terminal (entrar numa pasta e correr um comando) chega para a grande maioria dos tutoriais.

Os códigos funcionam em todos os modelos de IA?

As skills e os comandos são agnósticos ao modelo. O comportamento é definido pelo SKILL.md; o modelo que configuraste no hermes setup é o motor que executa. Modelos mais fortes costumam seguir as instruções com mais precisão.

E se o exemplo usar um caminho de ficheiro?

Os caminhos são ilustrativos. Substitui-os pelos caminhos reais do teu computador (por exemplo, o relatório de vendas que queres resumir).

Onde devo colocar as skills?

Sempre em ~/.hermes/skills/<nome-da-skill>/SKILL.md no macOS/Linux, ou %USERPROFILE%\.hermes\skills\<nome-da-skill>\SKILL.md no Windows. Uma pasta por skill, sempre com o ficheiro chamado SKILL.md.

Posso copiar o mesmo exemplo para Telegram e WhatsApp ao mesmo tempo?

Sim. Basta ligares os dois canais no hermes gateway setup e escolheres --deliver telegram ou --deliver whatsapp em cada agendamento.

Conclusão

A parte prática deste blog foi escrita para ser real e replicável: instala o Hermes, corre hermes setup, liga os canais de que precisas e copia os blocos com confiança. Começa por uma skill simples, valida o resultado e só depois automatiza o que for mais complexo.
