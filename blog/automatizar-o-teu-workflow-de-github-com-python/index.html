Automatizar o teu workflow de GitHub com Python

📅 17 Aug 2026 🏷️ Programadores ✍️ Hermes Agent

Sentes que passas mais tempo a rever Pull Requests, a etiquetar issues e a organizar releases no GitHub do que propriamente a escrever código? A gestão manual de repositórios consome horas preciosas de qualquer equipa de desenvolvimento. A boa notícia é que podes combinar a flexibilidade da linguagem Python com o poder do Hermes Agent para automatizar todo o teu workflow do GitHub de forma rápida, inteligente e segura.

O Poder do PyGithub Integrado com o Hermes Agent

A biblioteca PyGithub é uma das ferramentas mais robustas para interagir com a API REST do GitHub através de Python. Ela permite gerir repositórios, pull requests, commits, organizações e fluxos de CI/CD programmaticamente.

No entanto, quando aliamos o Python ao Hermes Agent, elevamos a automação a outro nível. Em vez de criares scripts isolados que requerem execução manual constante, o Hermes Agent atua como um orquestrador inteligente capaz de interpretar instruções em linguagem natural, tomar decisões com base no contexto do projeto e executar as tuas automações no momento certo.

Com esta combinação, podes automatizar facilmente:

  • Triagem de Issues: Classificação e atribuição automática de tarefas com base no conteúdo das mensagens.
  • Revisão de PRs: Análise preliminar de código e verificação de regras de estilo.
  • Gestão de Releases: Compilação automática de registos de alterações (changelogs) e criação de etiquetas de versão.
  • Acompanhamento de CI/CD: Monitorização do estado dos testes automatizados e notificação imediata de falhas.

Tutorial Prático: Automatizar o Workflow de GitHub

Vamos construir um fluxo prático passo a passo para integrares o teu repositório com o Python e o Hermes Agent.

Passo 1: Instalar as dependências e configurar o acesso

Primeiro, precisamos de instalar a biblioteca PyGithub no ambiente de desenvolvimento e definir um token de acesso pessoal (Personal Access Token) do GitHub com permissões de leitura e escrita nos teus repositórios.

pip install PyGithub
export GITHUB_TOKEN="ghp_seu_token_pessoal_aqui"

O comando pip install PyGithub instala a biblioteca de integração com o GitHub. O comando export guarda o teu token numa variável de ambiente segura, garantindo que as tuas credenciais nunca fiquem expostas diretamente no código da aplicação.

Passo 2: Criar o script Python de automação

Cria um ficheiro chamado github_manager.py no teu projeto. Este script consulta as issues abertas e cria um resumo automático das tarefas pendentes no repositório.

import os
from github import Github

def analisar_repositorio(repo_name):
    token = os.getenv("GITHUB_TOKEN")
    if not token:
        raise ValueError("A variável de ambiente GITHUB_TOKEN não está definida.")

    g = Github(token)
    repo = g.get_repo(repo_name)

    issues_abertas = repo.get_issues(state="open")
    prs_abertos = repo.get_pulls(state="open")

    relatorio = []
    relatorio.append(f"--- Relatório do Repositório: {repo.full_name} ---")
    relatorio.append(f"Total de Issues Abertas: {issues_abertas.totalCount}")
    
    for issue in issues_abertas:
        if not issue.pull_request:
            relatorio.append(f"  - Issue #{issue.number}: {issue.title}")

    relatorio.append(f"\nTotal de PRs Abertos: {prs_abertos.totalCount}")
    for pr in prs_abertos:
        relatorio.append(f"  - PR #{pr.number}: {pr.title} (Autor: {pr.user.login})")

    return "\n".join(relatorio)

if __name__ == "__main__":
    # Substitui pelo teu utilizador e repositório
    resultado = analisar_repositorio("utilizador/meu-projeto")
    print(resultado)

O código acima importa o módulo Github, autentica-se com o token configurado e acede aos dados do repositório indicado. Em seguida, percorre a lista de issues e pull requests ativos, gerando um relatório formatado em texto legível.

Passo 3: Criar a Skill para o Hermes Agent

Para que o Hermes Agent possa utilizar este script e automatizar o processo de forma autónoma, vamos definir uma skill personalizada. Cria um ficheiro chamado SKILL.md no diretório de skills do Hermes (geralmente em ~/.hermes/skills/github-automation/SKILL.md).

---
name: github-automation
description: Automatiza a análise e triagem de issues, PRs e releases no GitHub utilizando Python e PyGithub.
author: MarcTechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [github, python, automacao, ci-cd]
---

# github-automation
Skill para gerir e automatizar tarefas do GitHub através de scripts Python e da API do GitHub.

## When to Use
Utiliza esta skill quando for necessário analisar o estado do repositório, fazer triagem de issues abertas, verificar Pull Requests pendentes ou gerar relatórios de versão.

## Instruções
1. Certifica-te de que a variável de ambiente GITHUB_TOKEN está configurada corretamente no sistema.
2. Executa o script Python `github_manager.py` para recolher o estado atual das issues e PRs.
3. Analisa as informações obtidas e identifica quais os itens que necessitam de atenção urgente.
4. Apresenta um resumo estruturado ao utilizador com sugestões de próximos passos para o fluxo de CI/CD.

## Critérios de conclusão
- Leitura do repositório efetuada com sucesso sem erros de autenticação.
- Relatório de issues e PRs apresentado com clareza.
- Ações recomendadas disponibilizadas ao utilizador.

Este ficheiro SKILL.md contém os metadados em formato YAML e as instruções em Markdown que o Hermes Agent interpreta. A secção metadata categoriza a skill, enquanto a secção de instruções detalha exatamente a ordem de execução do agente.

Passo 4: Executar a Skill com o Hermes Agent

Com a skill configurada, podes verificar se ela está disponível e iniciá-la através do terminal interativo do Hermes Agent.

hermes skills list
hermes chat -s github-automation

O comando hermes skills list mostra todas as automações registadas no teu sistema. Ao executar hermes chat -s github-automation, inicias uma sessão interativa onde o agente carrega o contexto do teu projeto e executa a tarefa definida na skill.

Boas Práticas na Automação de CI/CD e Segurança

Ao automatizar rotinas no GitHub com scripts e agentes de Inteligência Artificial, é fundamental ter em conta alguns aspetos de segurança e otimização:

  • Princípio do Menor Privilégio: Configura o teu GitHub Personal Access Token apenas com as permissões estritamente necessárias (por exemplo, acesso apenas a leitura se a skill apenas gerar relatórios).
  • Gestão de Rate Limits: A API do GitHub impõe limites de requisições por hora. Certifica-te de que os teus scripts guardam resultados em cache sempre que possível.
  • Ambiente de Testes (Sandbox): Antes de permitir que o agente feche issues ou aprove PRs automaticamente, testa o fluxo num repositório secundário de testes.
