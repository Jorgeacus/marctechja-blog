Automatizar tarefas do dia a dia no teu computador com Python

📅 19 Aug 2026 📖 5 min de leitura 🏷️ Geral ✍️ Marcus

Organizar ficheiros na pasta de transferências, fazer cópias de segurança manuais ou preparar relatórios de vendas são tarefas que se repetem todos os dias e consomem tempo que podia ser usado em decisões importantes. A boa notícia é que podes delegar quase todo esse trabalho ao teu computador.

Porquê automatizar o computador com Python e Hermes Agent?

O Python é a linguagem ideal para automatização pessoal devido à sua simplicidade e vasta biblioteca standard. Quando combinamos a flexibilidade dos scripts em Python com a inteligência contextual do Hermes Agent, conseguimos ir além dos simples scripts mecânicos: criamos automações inteligentes que tomam decisões, leem documentos e organizam a tua vida digital de forma autónoma.

O que precisas para começar

Antes de criar as tuas primeiras automações, certifica-te de que tens o Python instalado no teu computador. Para elevar a tua produtividade com Inteligência Artificial, instala também o Hermes Agent através do terminal de comandos oficial:

No macOS ou Linux, abre o terminal e executa:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

No Windows, utiliza o PowerShell:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Guia Prático: Automatizar o teu computador em 4 Passos

Passo 1: Criar um script em Python para organizar a pasta de Downloads

O primeiro passo é acabar com a desarrumação na pasta de transferências. O script abaixo varre a tua pasta e move os ficheiros para subpastas categorizadas por tipo de extensão (Documentos, Imagens e Arquivos).

import os
import shutil
from pathlib import Path

# Define o caminho para a pasta de Downloads do utilizador
DOWNLOADS_DIR = Path.home() / "Downloads"

# Mapeamento de categorias e extensões de ficheiro
CATEGORIAS = {
    "Documentos": [".pdf", ".docx", ".txt", ".xlsx", ".pptx"],
    "Imagens": [".png", ".jpg", ".jpeg", ".gif", ".svg"],
    "Arquivos": [".zip", ".tar", ".gz", ".7z", ".rar"]
}

def organizar_downloads():
    if not DOWNLOADS_DIR.exists():
        print("A pasta Downloads não foi encontrada.")
        return

    for item in DOWNLOADS_DIR.iterdir():
        if item.is_file():
            extensao = item.suffix.lower()
            for categoria, extensoes in CATEGORIAS.items():
                if extensao in extensoes:
                    pasta_destino = DOWNLOADS_DIR / categoria
                    pasta_destino.mkdir(exist_ok=True)
                    shutil.move(str(item), str(pasta_destino / item.name))
                    print(f"Ficheiro movido: {item.name} -> {categoria}/")
                    break

if __name__ == "__main__":
    organizar_downloads()

Como funciona: O script utiliza a biblioteca pathlib para identificar a pasta pessoal do utilizador de forma compatível com Windows, macOS e Linux. Percorre cada ficheiro da pasta, verifica a extensão e move-o para a subpasta correspondente com a biblioteca shutil.

Passo 2: Automatizar backups compactados de pastas importantes

Fazer cópias de segurança diárias previne a perda acidental de dados. O script a seguir cria um ficheiro ZIP compactado com a data do dia a partir de qualquer pasta selecionada.

import shutil
from datetime import datetime
from pathlib import Path

def criar_backup(origem_dir, destino_dir):
    origem = Path(origem_dir)
    destino = Path(destino_dir)
    
    if not origem.exists():
        print("A pasta de origem não existe.")
        return

    destino.mkdir(parents=True, exist_ok=True)
    
    data_hoje = datetime.now().strftime("%Y-%m-%d_%H-%M")
    nome_arquivo = f"backup_trabalho_{data_hoje}"
    caminho_final = destino / nome_arquivo

    # Cria o ficheiro comprimido .zip
    arquivo_criado = shutil.make_archive(str(caminho_final), 'zip', str(origem))
    print(f"Backup concluído com sucesso: {arquivo_criado}")

if __name__ == "__main__":
    pasta_trabalho = Path.home() / "Documentos" / "Projetos"
    pasta_backups = Path.home() / "Backups"
    criar_backup(pasta_trabalho, pasta_backups)

Como funciona: A função shutil.make_archive comprime todo o conteúdo da pasta de origem num ficheiro ZIP carimbado com a data e hora exatas, garantindo um histórico organizado dos teus backups.

Passo 3: Agendar a execução automática dos scripts

Para que não precises de executar estes programas manualmente, podes agendar a sua execução periódica no sistema operativo:

  • Linux e macOS (Cron): Abre o terminal e digita crontab -e. Para executar o script de organização todos os dias às 18:00, adiciona a linha:
    0 18 * * * /usr/bin/python3 /caminho/para/organizar_downloads.py
  • Windows (Agendador de Tarefas): Cria uma "Tarefa Básica", define o gatilho diário e seleciona a ação "Iniciar um programa", indicando o executável do Python e o caminho do script.

Para além dos scripts rígidos em Python, podes utilizar o Hermes Agent para analisar dados e gerar relatórios de forma inteligente. Abaixo está uma skill pronta no formato oficial SKILL.md para resumir os teus relatórios do dia.

# Gerador de Relatório Diário

Analisa automaticamente a pasta de documentos do dia e gera um relatório claro com os pontos principais.

## When to Use
Usa esta skill no final do dia de trabalho para rever alterações, resumos de documentos ou tarefas concluídas.

## Instruções
1. Identifica os ficheiros de texto ou documentos modificados no dia de hoje na pasta do utilizador.
2. Lê o conteúdo e extrai as métricas, tópicos principais e reuniões registadas.
3. Formata um resumo conciso em formato Markdown contendo: Data, Tópicos Concluídos e Próximos Passos.
4. Salva o resultado num ficheiro chamado `relatorio_diario.md`.

## Critérios de conclusão
- O ficheiro `relatorio_diario.md` tem de ser criado com sucesso.
- O utilizador deve ver uma mensagem de confirmação no ecrã com o resumo das atividades.

Depois de guardar este ficheiro na tua pasta de skills (por exemplo, ~/.hermes/skills/gerador-relatorio-diario/SKILL.md), podes listar e executar a tua automação com os seguintes comandos do Hermes Agent:

hermes skills list

# Executar a skill interativamente
hermes chat -s gerador-relatorio-diario
