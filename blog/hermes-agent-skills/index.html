Skills no Hermes Agent — O que são e como criar

📅 25 Jul 2026 📖 10 min de leitura 🏷️ Avançado ✍️ Hermes Agent

As skills são o superpoder do Hermes Agent. Permitem estender as capacidades do agente com comandos personalizados, ferramentas externas e integrações com qualquer API ou serviço.

O que é uma Skill?

Uma skill é um conjunto de instruções que ensina o agente a executar uma tarefa específica. Pode ser tão simples como "pesquisar na web" ou tão complexa como "gerir uma base de dados inteira".

Tipos de Skills

  • Skills de Comando — o agente aprende um novo comando que pode ser invocado por texto
  • Skills de Ferramenta — integram APIs externas, bases de dados ou serviços web
  • Skills de Fluxo — combinam múltiplos passos num pipeline automatizado
  • Skills de Conhecimento — adicionam documentação ou contexto específico ao agente

O que é uma Skill no Hermes Agent real?

No Hermes Agent instalado na versão atual, uma skill é um ficheiro SKILL.md em Markdown, guardado numa pasta. Ao contrário de formatos declarativos de etapas fixas, o SKILL.md contém instruções em linguagem natural que o agente lê e depois decide, ele próprio, por onde começar — usando as ferramentas nativas (terminal, web, file).

Estrutura real de uma Skill (SKILL.md)

Cada skill vive em ~/.hermes/skills/<nome>/SKILL.md. A estrutura tem um cabeçalho (frontmatter) e um corpo narrativo:

---
name: pesquisar-web
description: Pesquisa na web e resume os resultados em poucas linhas.
version: 1.0.0
author: Hermes Agent
platforms: [linux, macos, windows]
---

# Pesquisar Web

## When to Use
Quando o utilizador pede para procurar informação atualizada na internet.

## Instruções
1. Usa a ferramenta `web_search` com o tema do utilizador.
2. Lê os 3-5 resultados mais relevantes.
3. Devolve um resumo claro, em português, com as fontes.

Repara: não há passos fixos nem ações llm.generate. O documento ensina o agente o que fazer; o agente é que executa.

Como criar e usar a skill no terminal

Guarda o ficheiro acima em ~/.hermes/skills/pesquisar-web/SKILL.md. Depois usa-a num chat:

hermes skills list                # ver skills disponíveis
hermes chat -s pesquisar-web      # abrir chat com a skill carregada

Ou, mais simples, pede ao agente para a criar por ti, diretamente no chat:

hermes chat -q "Cria uma skill chamada pesquisar-web que pesquisa na internet e resume os resultados em português"

Exemplo Prático: Skill de Email

---
name: enviar-email
description: Usa o CLI de email (Himalaya) para enviar uma mensagem.
version: 1.0.0
author: Hermes Agent
---

# Enviar Email

## When to Use
Quando o utilizador pede para enviar um email.

## Instruções
1. Confirma o destinatário e o assunto (pergunta se faltar).
2. Usa a ferramenta `terminal` com o CLI Himalaya:
   `himalaya send <to> --subject "<assunto>" --body "<texto>"`
3. Confirma que o email foi aceite pela fila de envio.

Para que esta skill funcione, é preciso ter o CLI himalaya instalado e autenticado (o agente usa ferramentas reais — não ações fictícias).

Skills simples vs. skills com scripts

Muitas skills do Hermes incluem uma subpasta scripts/ com um script de apoio que o agente corre pela ferramenta terminal. Este é o padrão real para tarefas que precisam de lógica concreta:

~/.hermes/skills/stream-launcher/
├── SKILL.md
└── scripts/
    └── stream_launcher.py   # o agente executa: python scripts/stream_launcher.py --site youtube

Onde Colocar as Skills

As skills ficam em ~/.hermes/skills/<nome>/SKILL.md. O Hermes carrega-as automaticamente ao iniciar, e podes ver as instaladas com hermes skills list.
