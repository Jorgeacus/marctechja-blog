Como Instalar o Hermes Agent no macOS, Linux e Windows

📅 28 Jul 2026 📖 12 min de leitura 🏷️ Tutorial ✍️ Hermes Agent

Este guia cobre a instalação do Hermes Agent nos três principais sistemas operativos. Ao final, terás o Hermes Agent a funcionar com o teu provider de IA preferido.

Pré-requisitos

  • Python 3.10 ou superior
  • Git
  • Uma chave de API de um provider de IA (ou vontade de usar modelos locais)

Instalação no macOS

O método oficial e recomendado usa o instalador de linha de comandos. Só precisas de ter o Bird (o HTML renderer) disponível e de abrir o Terminal:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

O script descarrega o CLI, coloca-o em ~/.local/bin/hermes e adiciona-o ao PATH. Confirma que ficou no sítio certo:

which hermes
hermes --version

Instalação no Linux

O processo é idêntico ao macOS, graças ao mesmo instalador oficial:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Para a maioria das distribuições (Debian/Ubuntu, Fedora, Arch) não são precisos pré-requisitos adicionais — o script trata das dependências. No caso de seres administrador da tua máquina, recomenda-se um ambiente virtual, mas o instalador já o configura por ti.

Instalação no Windows

  1. Abre o PowerShell como administrador.
  2. Se a execução de scripts ainda não estiver permitida, executa primeiro: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. Executa o instalador oficial nativo para Windows:
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Isto instala o Hermes Agent nativamente e adiciona o comando hermes ao PATH das tuas sessões do PowerShell.

Configuração de Providers

Após a instalação, cria um ficheiro .env na raiz do projeto com as tuas chaves de API:

OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...
DEEPSEEK_API_KEY=...

Se quiseres usar modelos locais com Ollama (gratuitos e sem saída de dados):

brew install ollama  # macOS
# ou: curl -fsSL https://ollama.ai/install.sh | sh  # Linux
ollama pull llama3.1

Verificar a Instalação

Executa o comando de teste:

hermes --version
hermes --help

Se vires a informação de versão e ajuda, a instalação está concluída. Recomenda-se também correr hermes doctor — é o comando de diagnóstico oficial que confirma que os providers e componentes estão acessíveis antes de começares a trabalhar.

Resolução de Problemas Comuns

"Comando não encontrado"

O instalador coloca o binário em ~/.local/bin/hermes. Se o comando não for encontrado, adiciona essa pasta ao PATH no teu ~/.zshrc (ou equivalente) e abre um novo terminal:

export PATH="$HOME/.local/bin:$PATH"

O instalador falhou a meio

Verifica a ligação à internet e tenta de novo — o instalador é idempotente e pode ser reexecutado em segurança. No macOS, instala as ferramentas de linha de comandos do Xcode se a compilação falhar: xcode-select --install. No Linux, sudo apt install build-essential.

Problemas com providers ou configuração

Corre hermes doctor para um diagnóstico completo da configuração e das dependências.

Primeira Configuração

Com a instalação concluída, o próximo passo é fazer a configuração inicial. O Hermes Agent oferece um assistente que cria o ficheiro de configuração e te guia na escolha do provider:

  1. Executa hermes setup — o assistente interativo cria a estrutura de diretórios e o ficheiro ~/.hermes/.env de exemplo.
  2. Escolhe o provider principal (OpenAI, Anthropic, Gemini, DeepSeek ou local).
  3. Introduz a chave de API quando solicitado. O assistente guarda-a no .env e mantém-na fora do controlo de versões.
  4. Define o modelo predefinido. Podes deixar o valor padrão e alterar depois por tarefa.

Se preferires editar manualmente, os ficheiros ficam em ~/.hermes/ e podes ajustar modelos, temperatura e tempo limite de cada pedido.

Primeiro Agente

Para confirmares que tudo funciona, abre um chat com o agente e faz-lhe uma pergunta direta:

hermes chat -q "Olá, apresenta-te em duas frases"

Se a resposta aparecer sem erros, tens o pipeline completo a funcionar: o Hermes Agent comunicou com o provider, recebeu a resposta e devolveu-a no terminal.

Manutenção e Atualizações

Como é uma ferramenta em evolução rápida, é boa prática atualizar regularmente voltando a correr o mesmo instalador oficial (é idempotente):

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

No Windows, repete iex (irm https://hermes-agent.nousresearch.com/install.ps1). O instalador substitui o binário antigo pela versão mais recente sem tocar na tua configuração em ~/.hermes/.

Requisitos Mínimos

Para uma experiência fluida, recomenda-se: um processador de 64 bits, pelo menos 4 GB de RAM (8 GB se usares modelos locais) e 2 GB de espaço livre em disco. O Hermes Agent corre em macOS 11+, distribuições Linux recentes e Windows 10+.

Não precisas de uma máquina potente para começar — o processamento mais pesado acontece na API do provider remoto. Só se quiseres correr modelos locais é que o hardware passa a importar, porque o modelo vive no teu computador.

Perguntas Frequentes

Posso ter vários providers ao mesmo tempo?

Sim. O Hermes Agent é multi-provider: podes definir vários providers e escolher o modelo ideal para cada skill ou tarefa, bastando indicar o provider no comando.

E se não quiser pagar por uma API?

Usa modelos locais com o Ollama. A instalação local é gratuita e os teus dados nunca saem do teu computador — um bom ponto de partida para testar.

O que devo fazer se a instalação falhar a meio?

Volta ao passo onde falhou e confirma os pré-requisitos (ligação à internet e xcode-select --install no macOS). O instalador oficial é idempotente — basta reexecutá-lo.

Conclusão

Instalar o Hermes Agent é rápido em qualquer sistema operativo, e a configuração inicial demora poucos minutos. Com o agente funcional, estás pronto para o passo seguinte: criar a tua primeira skill e começar a automatizar tarefas do dia a dia.
