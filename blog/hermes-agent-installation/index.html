Como Instalar o Hermes Agent no macOS, Linux e Windows

📅 28 Jul 2026 📖 8 min de leitura 🏷️ Tutorial

Este guia cobre a instalação do Hermes Agent nos três principais sistemas operativos. Ao final, terás o Hermes Agent a funcionar com o teu provider de IA preferido.

Pré-requisitos

  • Python 3.10 ou superior
  • Git
  • Uma chave de API de um provider de IA (ou vontade de usar modelos locais)

Instalação no macOS

No macOS, tens duas opções: Homebrew ou instalação manual com pip.

Opção 1 — Homebrew (recomendado):

brew tap hermes-agent/tap
brew install hermes-agent

Opção 2 — Pip:

git clone https://github.com/HermesAgent/hermes-agent.git
cd hermes-agent
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install -e .

Instalação no Linux

git clone https://github.com/HermesAgent/hermes-agent.git
cd hermes-agent
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install -e .

Para distribuições baseadas em Debian/Ubuntu, certifica-te de que tens o Python 3.10+ instalado:

sudo apt update
sudo apt install python3 python3-pip python3-venv git

Instalação no Windows

  1. Instala o Python 3.10+ a partir do python.org (marca "Add to PATH")
  2. Instala o Git a partir do git-scm.com
  3. Abre o PowerShell como administrador e executa:
git clone https://github.com/HermesAgent/hermes-agent.git
cd hermes-agent
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
pip install -e .

Configuração de Providers

Após a instalação, cria um ficheiro .env na raiz do projeto com as tuas chaves de API:

OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...
DEEPSEEK_API_KEY=...

Se quiseres usar modelos locais com Ollama:

brew install ollama  # macOS
# ou: curl -fsSL https://ollama.ai/install.sh | sh  # Linux
ollama pull llama3.1
ollama pull hermes-agent  # modelo otimizado

Verificar a Instalação

Executa o comando de teste:

hermes --version
hermes --help

Se vires a informação de versão e ajuda, a instalação está concluída.

Resolução de Problemas Comuns

"Comando não encontrado"

Certifica-te de que o ambiente virtual está ativo (source venv/bin/activate no macOS/Linux, venv\Scripts\activate no Windows).

Erro de dependências

Algumas dependências podem exigir compilação. No macOS, instala as ferramentas de linha de comandos do Xcode: xcode-select --install. No Linux, sudo apt install build-essential.
