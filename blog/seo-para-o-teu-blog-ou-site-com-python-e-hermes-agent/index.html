SEO para o teu blog ou site com Python e Hermes Agent

📅 19 Aug 2026 📖 8 min de leitura 🏷️ Criadores de Conteúdo ✍️ Marcus

Analisar palavras-chave, redigir meta descriptions e tentar perceber porque é que os teus artigos não alcançam as primeiras posições do Google são tarefas que consomem horas preciosas a qualquer criador de conteúdo. Otimizar o teu site para motores de pesquisa (SEO) é essencial para atrair tráfego orgânico qualificado, mas pode tornar-se extremamente repetitivo. A boa notícia é que podes automatizar grande parte deste processo combinando a flexibilidade do Python com a inteligência do Hermes Agent. Neste guia prático, vais aprender a criar rotinas automatizadas para auditorias de palavras-chave, otimização de títulos e metadados, análise de backlinks e geração de relatórios de desempenho.

Porquê automatizar o SEO com o Hermes Agent e Python?

O SEO moderno exige uma análise constante de dados e a produção de conteúdos perfeitamente otimizados. Enquanto os scripts em Python tratam do processamento pesado de dados — como extração de métricas, cálculo de densidade de termos e leitura de ficheiros CSV —, o Hermes Agent atua como o cérebro da operação. O agente interpreta esses dados, sugere melhorias editoriais, gera títulos apelativos com alta taxa de clique (CTR) e formata relatórios executivos prontos a usar.

Passo 1: Instalar o Hermes Agent

Se ainda não tens o Hermes Agent instalado, começa por instalar a ferramenta no teu sistema com um único comando no terminal:

# macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell como Administrador)
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Este comando descarrega e instala o executável oficial do Hermes Agent e adiciona o comando hermes ao teu terminal.

Passo 2: Criar uma Skill de Otimização SEO no Hermes Agent

Para começar, vamos estruturar uma skill personalizada no Hermes Agent. As skills permitem ao agente executar tarefas específicas seguindo diretrizes bem definidas. No teu sistema, cria o diretório para a skill e adiciona o ficheiro SKILL.md.

Guarda o ficheiro em ~/.hermes/skills/seo_optimizer/SKILL.md com a seguinte estrutura oficial:

---
name: seo_optimizer
description: Otimiza artigos de blog, títulos e meta descriptions com base em palavras-chave e boas práticas de SEO.
author: MarcTechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [seo, python, marketing, conteudo]
---

# SEO Optimizer

Esta skill analisa rascunhos de artigos e dados de pesquisa para otimizar a visibilidade nos motores de busca.

## When to Use
Utiliza esta skill quando precisares de rever rascunhos de artigos, gerar títulos otimizados para SEO, criar meta descriptions persuasivas ou analisar a densidade de palavras-chave.

## Instruções
1. Analisa o texto ou rascunho fornecido pelo utilizador.
2. Se o utilizador pedir uma análise técnica do artigo, executa o script Python seo_analyzer.py (na mesma pasta da skill) com o ficheiro do artigo como argumento: python3 seo_analyzer.py artigo.md — o script devolve um relatório JSON com a contagem de palavras e as palavras-chave mais frequentes.
3. Identifica a palavra-chave principal e termos secundários (cauda longa).
4. Gera 3 opções de Títulos SEO (H1) com menos de 60 caracteres, apelativos e focados na intenção de busca.
5. Cria 2 opções de Meta Description (entre 140 e 155 caracteres) com uma chamada à ação (CTA) clara.
6. Revisa a estrutura de cabeçalhos (H2, H3) para garantir uma leitura fluida e semanticamente correta.
7. Fornece recomendações de links internos e termos relacionados a incluir.

## Critérios de conclusão
- Apresentar sugestões claras de títulos e metadados com contagem de caracteres.
- Se o script Python foi executado, citar a palavra-chave mais frequente e a densidade percentual calculada.
- Entregar um resumo de otimização estruturado e pronto a aplicar no CMS.

O que este ficheiro faz: O cabeçalho YAML define os metadados necessários para o Hermes Agent reconhecer a skill. O corpo do ficheiro instrui o modelo de IA sobre exatamente como processar o teu conteúdo, aplicando regras de SEO rigorosas em cada execução.

Passo 3: Desenvolver o Script Python para Auditoria de Conteúdo

Agora vamos criar um script em Python que faz a leitura do teu artigo e calcula métricas essenciais, como a contagem total de palavras e a densidade de palavras-chave. Este script serve de suporte ao Hermes Agent.

Cria um ficheiro chamado seo_analyzer.py dentro da pasta da skill (~/.hermes/skills/seo_optimizer/seo_analyzer.py), para que o Hermes Agent consiga encontrar e executar o script quando a skill for ativada:

import re
import json
import sys
from collections import Counter

def analisar_texto(caminho_ficheiro):
    try:
        with open(caminho_ficheiro, 'r', encoding='utf-8') as f:
            conteudo = f.read().lower()

        # Extração de palavras ignorando pontuação e termos muito curtos
        palavras = re.findall(r'\b[a-záàâãéêíóôõúç]{4,}\b', conteudo)
        total_palavras = len(palavras)

        if total_palavras == 0:
            return json.dumps({"erro": "O ficheiro está vazio ou não contém palavras válidas."})

        # Contagem da frequência de termos
        frequencia = Counter(palavras)
        mais_comuns = frequencia.most_common(8)

        relatorio = {
            "total_palavras": total_palavras,
            "palavras_chave_frequentes": [
                {"palavra": palavra, "contagem": qtd, "densidade": f"{(qtd / total_palavras) * 100:.2f}%"}
                for palavra, qtd in mais_comuns
            ]
        }

        return json.dumps(relatorio, ensure_ascii=False, indent=2)

    except Exception as e:
        return json.dumps({"erro": str(e)})

if __name__ == "__main__":
    ficheiro = sys.argv[1] if len(sys.argv) > 1 else "artigo.md"
    print(analisar_texto(ficheiro))

O que o código faz: O script abre o artigo em texto limpo ou Markdown, filtra palavras irrelevantes, calcula a densidade percentual das palavras mais utilizadas e devolve um relatório em JSON. O Hermes Agent pode consumir este JSON para verificar se a palavra-chave alvo está com uma densidade equilibrada (idealmente entre 1% e 2.5%).

Passo 4: Executar a Automação e Gerar Relatórios no Hermes Agent

Com a skill configurada e o script Python pronto, podes verificar se a skill está ativa no teu ambiente e iniciar a sessão de otimização.

Primeiro, confirma que o Hermes Agent detetou a tua nova skill:

hermes skills list

Para iniciar o processo de otimização SEO com a skill criada, executa o seguinte comando no terminal:

hermes chat -s seo_optimizer

Dentro do chat interativo do Hermes, podes passar instruções como:

Executa o script Python 'seo_analyzer.py' no meu ficheiro 'novo_artigo.md'. Com base no relatório JSON gerado, otimiza o título e escreve duas meta descriptions apelativas.

O Hermes Agent executará a análise técnica e aplicará a inteligência contextual para entregar o título perfeito e os metadados prontos a publicar no teu blog.

Análise de Dados do Google Search Console com Python

Para analisar o desempenho global do teu site, cria um script chamado gsv_analyzer.py que lê o CSV exportado do Google Search Console e devolve um resumo JSON:

import csv
import json
import sys

def processar_csv_gsv(caminho_csv):
    """Processa um CSV exportado do Google Search Console e devolve um resumo JSON.

    Colunas esperadas: Query, Clicks, Impressions, CTR, Position.
    """
    total_impressoes = 0
    linhas = []
    with open(caminho_csv, "r", encoding="utf-8") as f:
        leitor = csv.DictReader(f)
        for row in leitor:
            try:
                impressoes = int(row.get("Impressions", 0) or 0)
                cliques = int(row.get("Clicks", 0) or 0)
                posicao = float(row.get("Position", 0) or 0)
                total_impressoes += impressoes
                linhas.append({
                    "query": row.get("Query", "").strip(),
                    "cliques": cliques,
                    "impressoes": impressoes,
                    "ctr": round((cliques / impressoes * 100), 2) if impressoes else 0,
                    "posicao_media": round(posicao, 2),
                })
            except ValueError:
                continue

    if not linhas:
        return json.dumps({"erro": "Ficheiro CSV vazio ou com formato inesperado."})

    linhas.sort(key=lambda x: x["impressoes"], reverse=True)

    # Oportunidades: muitas impressões mas baixa CTR (ideal para novos títulos)
    oportunidades = [l for l in linhas if l["impressoes"] >= 1000 and l["ctr"] < 2.0]

    resumo = {
        "total_queries": len(linhas),
        "total_impressoes": total_impressoes,
        "melhores_queries": linhas[:10],
        "oportunidades_ctr": oportunidades[:10],
    }
    return json.dumps(resumo, ensure_ascii=False, indent=2)

if __name__ == "__main__":
    print(processar_csv_gsv(sys.argv[1] if len(sys.argv) > 1 else "dados.csv"))

O que este código faz: O script processar_csv_gsv lê o CSV exportado do Google Search Console, calcula a taxa de clique (CTR) de cada pesquisa, ordena pelas impressões e devolve um relatório JSON com as queries de melhor desempenho e as oportunidades de melhoria (muitas impressões, pouca CTR) — dados que o Hermes Agent pode depois transformar em novos títulos e metadados.

Análise de Backlinks e Relatórios de Desempenho

Com o script gsv_analyzer.py a tratar os dados do Google Search Console, podes agora usar o Hermes Agent para interpretar os resultados e aplicar otimizações concretas:

  • Identificação de Oportunidades: Pede ao Hermes Agent para cruzar palavras-chave com muitas impressões mas pouca taxa de clique (CTR), gerando novas ideias de títulos.
  • Análise de Backlinks Perdidos: Processa listas de links de entrada (exportadas de Ahrefs ou Semrush) para identificar domínios de autoridade que deixaram de apontar para o teu blog.
  • Relatórios Semanais: Cria uma rotina automatizada em Python que gera um resumo em Markdown com os teus artigos mais visitados e as posições médias no Google.
