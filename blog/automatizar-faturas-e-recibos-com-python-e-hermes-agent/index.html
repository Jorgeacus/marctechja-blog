Automatizar faturas e recibos com Python e Hermes Agent

📅 23 Nov 2026 📖 10 min de leitura 🏷️ Empresas ✍️ Marcus

Emitir faturas, gerar recibos de pagamento em formato PDF e enviá-los manualmente por e-mail a cada cliente é um dos processos administrativos que mais tempo consome em pequenas e grandes empresas. Quando o volume de vendas cresce, o trabalho repetitivo de copiar dados de compras, calcular impostos e anexar ficheiros torna-se propenso a erros humanos e atrasos operacionais.

A combinação da linguagem Python com o Hermes Agent permite transformar todo este fluxo numa operação 100% autónoma. O Hermes Agent atua como a camada de inteligência capaz de interpretar dados brutos de vendas, validar a informação dos clientes e orquestrar a execução de scripts Python responsáveis por construir os documentos digitais e expedir as notificações financeiras.

Neste guia prático, vai aprender a desenhar e implementar uma solução completa de automação de faturação, desde a estrutura de templates até ao envio por correio eletrónico, adaptável a lojas virtuais, prestadores de serviços e empresas de qualquer dimensão.

Como Funciona a Arquitetura da Automação

Para criar um sistema de emissão de faturas robusto e seguro, é recomendável dividir o trabalho entre o raciocínio situacional da inteligência artificial e a determinação determinística do código Python. O Hermes Agent não substitui o código de geração de PDFs; em vez disso, ele organiza a informação recebida (como dados de um formulário ou extrato de vendas), aciona os scripts corretos e gere exceções de forma autónoma.

O fluxo de trabalho completo é composto por quatro etapas interligadas:

  • Leitura e Validação de Dados: O agente recebe a informação da venda (cliente, NIF, itens comprados, valores e taxas de IVA).
  • Geração do Documento PDF: Um script Python utiliza bibliotecas especializadas para preencher um modelo (template) visual com os dados validados.
  • Envio de Notificação e Anexo: O sistema estabelece uma ligação segura via SMTP para remeter a fatura ou recibo diretamente para a caixa de correio do cliente.
  • Registo e Organização: O ficheiro PDF gerado é arquivado numa estrutura de pastas organizada por ano, mês e número do documento.

Para garantir a máxima integridade e conformidade dos dados financeiros, o Hermes Agent interage com o ambiente local através de skills personalizadas. Se ainda não configurou o seu ambiente de trabalho com esta ferramenta, pode consultar o nosso guia sobre como instalar e configurar o Hermes Agent.

Passo a Passo: Construir o Sistema de Automação de Faturas

Siga os passos detalhados abaixo para estruturar a sua aplicação em Python e a respetiva integração com o Hermes Agent.

Passo 1: Preparar o ambiente Python e as dependências necessárias

O primeiro passo consiste em instalar as bibliotecas Python que vão gerir a criação dos ficheiros PDF e o manuseamento de modelos de texto. Vamos utilizar a biblioteca reportlab para a geração programática de ficheiros PDF com layout profissional.

Execute o seguinte comando no seu terminal para preparar o ambiente:

pip install reportlab pydantic python-dotenv

Após a instalação das dependências, crie um script Python chamado faturacao_engine.py. Este ficheiro conterá a função responsável por gerar a fatura em PDF a partir de um dicionário de dados.

import os
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication
from reportlab.lib.pagesizes import letter
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Table, TableStyle
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib import colors

def gerar_pdf_fatura(dados_fatura: dict, ficheiro_saida: str) -> str:
    """Gera um ficheiro PDF de fatura profissional a partir de um dicionario de dados."""
    doc = SimpleDocTemplate(ficheiro_saida, pagesize=letter)
    elementos = []
    estilos = getSampleStyleSheet()
    
    # Cabecalho da Empresa
    estilo_titulo = ParagraphStyle('Titulo', parent=estilos['Heading1'], fontSize=20, textColor=colors.HexColor('#1E293B'))
    elementos.append(Paragraph(f"FATURA #{dados_fatura['numero_fatura']}", estilo_titulo))
    elementos.append(Spacer(1, 12))
    
    # Detalhes do Emitente e Cliente
    info_texto = f"""
    Emitente: {dados_fatura['empresa_nome']}

    NIF Emitente: {dados_fatura['empresa_nif']}


    Cliente: {dados_fatura['cliente_nome']}

    NIF Cliente: {dados_fatura['cliente_nif']}

    Email: {dados_fatura['cliente_email']}

    Data: {dados_fatura['data']}
    """
    elementos.append(Paragraph(info_texto, estilos['Normal']))
    elementos.append(Spacer(1, 20))
    
    # Tabela de Itens
    tabela_dados = [['Descricao', 'Qtd', 'Preco Unit.', 'Total']]
    subtotal = 0.0
    
    for item in dados_fatura['itens']:
        total_item = item['quantidade'] * item['preco_unitario']
        subtotal += total_item
        tabela_dados.append([
            item['descricao'],
            str(item['quantidade']),
            f"{item['preco_unitario']:.2f} €",
            f"{total_item:.2f} €"
        ])
    
    taxa_iva = dados_fatura.get('taxa_iva', 0.23)
    total_iva = subtotal * taxa_iva
    total_final = subtotal + total_iva
    
    tabela_dados.append(['', '', 'Subtotal:', f"{subtotal:.2f} €"])
    tabela_dados.append(['', '', f"IVA ({(taxa_iva*100):.0f}%):", f"{total_iva:.2f} €"])
    tabela_dados.append(['', '', 'Total Final:', f"{total_final:.2f} €"])
    
    tabela = Table(tabela_dados, colWidths=[220, 60, 100, 100])
    tabela.setStyle(TableStyle([
        ('BACKGROUND', (0, 0), (-1, 0), colors.HexColor('#F1F5F9')),
        ('TEXTCOLOR', (0, 0), (-1, 0), colors.HexColor('#0F172A')),
        ('ALIGN', (0, 0), (-1, -1), 'LEFT'),
        ('ALIGN', (1, 0), (-1, -1), 'RIGHT'),
        ('FONTNAME', (0, 0), (-1, 0), 'Helvetica-Bold'),
        ('BOTTOMPADDING', (0, 0), (-1, 0), 8),
        ('GRID', (0, 0), (-1, -4), 0.5, colors.HexColor('#E2E8F0')),
        ('FONTNAME', (2, -3), (-1, -1), 'Helvetica-Bold'),
    ]))
    
    elementos.append(tabela)
    doc.build(elementos)
    return ficheiro_saida

def enviar_fatura_email(dados_fatura: dict, caminho_pdf: str, smtp_config: dict) -> bool:
    """Envia o PDF gerado por e-mail para o cliente."""
    msg = MIMEMultipart()
    msg['From'] = smtp_config['usuario']
    msg['To'] = dados_fatura['cliente_email']
    msg['Subject'] = f"Fatura #{dados_fatura['numero_fatura']} - {dados_fatura['empresa_nome']}"
    
    corpo = f"""Estimado(a) {dados_fatura['cliente_nome']},

Agradecemos a sua preferencia. Em anexo, encontra a fatura #{dados_fatura['numero_fatura']} referente aos servicos prestados.

Com os melhores cumprimentos,
{dados_fatura['empresa_nome']}
"""
    msg.attach(MIMEText(corpo, 'plain'))
    
    with open(caminho_pdf, 'rb') as f:
        anexo = MIMEApplication(f.read(), _subtype='pdf')
        anexo.add_header('Content-Disposition', 'attachment', filename=os.path.basename(caminho_pdf))
        msg.attach(anexo)
        
    try:
        servidor = smtplib.SMTP(smtp_config['servidor'], smtp_config['porta'])
        servidor.starttls()
        servidor.login(smtp_config['usuario'], smtp_config['senha'])
        servidor.send_message(msg)
        servidor.quit()
        return True
    except Exception as e:
        print(f"Erro ao enviar email: {e}")
        return False

O código acima define duas funções reutilizáveis: gerar_pdf_fatura trata da construção visual do ficheiro PDF com calculo automático de IVA e layout estruturado; enviar_fatura_email faz o envio seguro do ficheiro anexo através do protocolo SMTP. Para aprofundar a gestão automatizada de correio eletrónico, consulte também o nosso artigo sobre automação de e-mail com Python e IA.

Passo 2: Criar a Skill Personalizada no Hermes Agent

Com a infraestrutura de código Python pronta, é altura de expor estas capacidades ao Hermes Agent. Para isso, criamos um ficheiro SKILL.md na diretoria de competências do agente (geralmente em ~/.hermes/skills/emitir-fatura/SKILL.md).

As skills do Hermes Agent utilizam uma especificação em Markdown com um cabeçalho YAML contendo metadados essenciais para que a IA saiba quando e como invocar a ferramenta.

---
name: emitir-fatura
description: Processa a informacao de uma venda, gera a fatura respetiva em PDF e envia-a por e-mail para o cliente.
author: MarcTechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [faturacao, pdf, email, automacao, empresas]
---

# emitir-fatura

Esta skill permite ao Hermes Agent emitir faturas e recibos em PDF e envia-los automaticamente aos clientes por correio eletronico.

## When to Use

Use esta skill quando o utilizador solicitar a emissao, criacao ou envio de uma fatura ou recibo para um cliente especifico, fornecendo os detalhes dos produtos ou servicos vendidos.

## Instruções

1. **Recolher e Validar Dados:** Verifique se tem a informacao completa:
   - Nome e NIF do Cliente
   - Email do Cliente
   - Lista de itens (descricao, quantidade, preco unitario)
   - Numero da fatura (ou gerar um automatico baseado na data)

2. **Executar o Script Python:**
   - Crie um ficheiro JSON temporario com os dados estruturados do pedido.
   - Execute o script Python `faturacao_engine.py` para construir o PDF no diretorio `./faturas/`.

3. **Confirmar o Envio:**
   - Dispare a funcao de envio por e-mail.
   - Guarde a fatura gerada na pasta de arquivo local `./faturas/emitidas/`.

## Critérios de conclusão

- Ficheiro PDF gerado com sucesso sem erros de sintaxe ou layout.
- Confirmacao de envio da mensagem e anexo via SMTP.
- Resumo claro apresentado ao utilizador no chat informando o total faturado e o destinatario.

Esta estrutura padronizada segue o formato oficial do ecossistema Hermes Agent, permitindo que o modelo de linguagem identifique os parâmetros necessários e os passos de execução sem falhas contextuais. Para saber mais sobre como projetar extensões personalizadas, veja o nosso guia sobre criação de skills no Hermes Agent.

Passo 3: Executar e Interagir com o Hermes Agent

Após guardar a nova skill, confirme que o Hermes Agent a reconhece listando as ferramentas disponíveis no terminal com o comando oficial:

hermes skills list

Para iniciar a automação e solicitar a emissão de uma fatura através de uma linguagem natural simples, utilize o comando interativo da CLI apontando para a skill criada:

hermes chat -s emitir-fatura

Na interface de conversa do agent, pode simplesmente inserir um pedido como este:

"Emite uma fatura para a empresa Inovacao Digital Lda, NIF 509876543, email contacto@inovacaodigital.pt. 
Servicos prestados: 2 dias de Consultoria Tecnologica a 450 EUR/dia e 1 Licenca de Software a 150 EUR. 
Aplica a taxa normal de IVA."

O Hermes Agent interpretará a instrução, estruturará os dados no formato interno e invocará o script Python para produzir e enviar a fatura em escassos segundos.

Cuidados, Limitações e Erros Comuns

Apesar de a automação trazer enorme eficiência às operações diárias, existem aspetos técnicos e legais essenciais que devem ser acautelados ao lidar com dados financeiros e de faturação.

1. Conformidade Fiscal e Certificação de Software

Em jurisdições como Portugal ou Espanha, a faturação a clientes exige frequentemente o uso de software devidamente certificado pelas autoridades tributárias (como a Autoridade Tributária e Aduaneira - AT), com a inclusão de assinaturas digitais ou códigos QR específicos (ex: QRCodes e chaves hash em faturas). O script Python aqui apresentado serve para a geração autónoma de recibos internos, proformas, orçamentos ou faturas num ambiente de simulação e suporte operacional. Caso a sua empresa seja obrigada a emitir faturas certificadas, o Hermes Agent deve ser integrado com a API do seu software de faturação certificado em vez de gerar o PDF diretamente de raiz.

2. Limitações de Envio via SMTP

Servidores de e-mail padrão (como o Gmail, Outlook ou servidores cPanel) impõem limites rigorosos quanto ao número de mensagens enviadas por hora ou por dia. Tentar enviar centenas de faturas num único bloco através de um e-mail pessoal pode resultar no bloqueio temporário da conta de correio ou na classificação das mensagens como spam. Para operações de grande escala, utilize serviços dedicados de e-mail transacional (como SendGrid, Mailgun ou Amazon SES).

3. Tratamento de Exceções e Proteção de Dados

Erros na sintaxe do endereço de e-mail do cliente ou falhas na ligação à rede podem interromper a execução do script. Garanta que o seu código Python implementa blocos de tratamento de exceções (try/except) e guarda num ficheiro de log todas as faturas que falharam o envio para posterior reprocessamento. Além disso, lembre-se de proteger a informação pessoal de clientes e chaves de e-mail, aplicando as boas práticas de segurança e privacidade com o Hermes Agent.

Conclusão

Automatizar a criação e o envio de faturas e recibos com o Python e o Hermes Agent transforma um processo burocrático demorado numa tarefa de fundo rápida, precisa e sem atritos. A capacidade do Hermes Agent para estruturar pedidos em linguagem natural combinada com a precisão dos scripts Python proporciona o equilíbrio ideal entre flexibilidade e fiabilidade operacional.
