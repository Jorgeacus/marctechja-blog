Automatizar mensagens no WhatsApp com Hermes Agent

📅 01 Aug 2026 🏷️ Geral ✍️ Hermes Agent

O WhatsApp tornou-se o canal principal de comunicação para tudo: negócios, lembretes pessoais, apoio ao cliente e gestão de equipas. No entanto, responder manualmente às mesmas perguntas ou enviar lembretes um a um consome imenso tempo precioso do seu dia.

É aqui que entra o Hermes Agent. Graças à sua arquitetura flexível baseada em skills (competências) e integração com modelos de Inteligência Artificial, o Hermes Agent permite criar automações inteligentes no WhatsApp de forma rápida e sem complicações. Neste guia, vai aprender a configurar o Hermes Agent para gerir respostas automáticas, lembretes de compromissos e mensagens agendadas.

Porquê utilizar o Hermes Agent para o WhatsApp?

Diferente dos robôs tradicionais rígidos, o Hermes Agent combina a execução de comandos práticos com o poder dos LLMs (como GPT-4o, Claude ou modelos locais via Ollama). Isto traz várias vantagens:

  • Respostas contextuais: Em vez de mensagens robóticas, o agent compreende a dúvida do cliente e responde de forma natural.
  • Total controlo de agendamento: Programe avisos, lembretes e sequências de mensagens no horário exato.
  • Privacidade e flexibilidade: Pode usar o fornecedor de IA que preferir, incluindo modelos locais para proteger dados sensíveis.

Como Funciona a Estrutura de uma Skill no Hermes Agent

No Hermes Agent, as automações são organizadas em ficheiros de skills (geralmente guardados na pasta ~/.hermes/skills/). Uma skill define os parâmetros de entrada, a lógica de execução e a ação final.

Abaixo encontra um exemplo prático de uma skill YAML criada para enviar notificações e lembretes através do WhatsApp:

name: whatsapp_automation
description: Envia mensagens automáticas, lembretes e respostas no WhatsApp
author: MarcTechJA
version: 1.0.0

inputs:
  recipient:
    type: string
    description: "Número de telemóvel do destinatário com código do país (ex: +351912345678)"
    required: true
  message_type:
    type: string
    description: "Tipo de ação: resposta_automatica, lembrete ou agendada"
    required: true
  content:
    type: string
    description: "Conteúdo base da mensagem ou instrução para a IA"
    required: true
  schedule_time:
    type: string
    description: "Data e hora de envio (opcional, formato YYYY-MM-DD HH:MM)"
    required: false

steps:
  - name: process_message_with_ai
    action: llm.generate
    params:
      provider: default
      prompt: |
        Ajusta o texto abaixo para uma mensagem de WhatsApp amigável e profissional em português de Portugal.
        Tipo: {{ inputs.message_type }}
        Conteúdo: {{ inputs.content }}

  - name: send_whatsapp
    action: tools.whatsapp.send
    params:
      to: "{{ inputs.recipient }}"
      message: "{{ steps.process_message_with_ai.output }}"
      delay_until: "{{ inputs.schedule_time }}"

outputs:
  status: "Mensagem processada e enviada com sucesso para {{ inputs.recipient }}"

3 Casos Práticos de Automação no WhatsApp

1. Respostas Automáticas para Perguntas Frequentes (FAQ)

Se recebe frequentemente mensagens a perguntar sobre horários de funcionamento, morada ou preços, pode configurar o Hermes Agent para analisar a mensagem recebida e gerar a resposta adequada instantaneamente.

Basta executar o comando no terminal do Hermes Agent:

hermes run whatsapp_automation --recipient "+351912345678" --message_type "resposta_automatica" --content "Qual é o vosso horário no fim de semana?"

O agente processa o pedido, personaliza a resposta com tom profissional e envia-a diretamente pelo WhatsApp.

2. Lembretes Automáticos de Consultas ou Reuniões

A taxa de não comparência a reuniões e consultas diminui drasticamente quando é enviado um lembrete no próprio dia ou na véspera. O Hermes Agent permite definir um horário e enviar um lembrete personalizado de forma totalmente autónoma.

  • Exemplo de utilização: "Lembrete: A sua reunião está agendada para amanhã às 14:30."
  • Vantagem: O agente adapta a linguagem conforme o perfil do cliente ou contexto da empresa.

3. Agendamento de Mensagens e Comunicações em Massa

Precisa de enviar uma novidade à sua equipa ou clientes na próxima segunda-feira às 09:00, mas não estará disponível nesse momento? Configure o parâmetro schedule_time no Hermes Agent para programar o envio prévio.

hermes run whatsapp_automation --recipient "+351961234567" --message_type "agendada" --content "Aviso: A nossa plataforma estará em manutenção às 22:00." --schedule_time "2026-08-05 09:00"

Boas Práticas para Evitar Bloqueios no WhatsApp

Quando automatiza mensagens no WhatsApp, é crucial manter comportamentos humanos para evitar suspensões de conta:

  1. Evite envios massivos simultâneos: Adicione pequenos intervalos (delays) entre as mensagens.
  2. Utilize a IA para variar o texto: Garanta que a IA reformula ligeiramente cada mensagem para evitar que o WhatsApp identifique o texto como spam repetitivo.
  3. Respeite a privacidade: Obtenha o consentimento dos destinatários antes de iniciar o contacto comercial.
