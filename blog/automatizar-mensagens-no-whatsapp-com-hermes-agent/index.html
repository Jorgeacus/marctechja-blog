Automatizar mensagens no WhatsApp com Hermes Agent

📅 01 Aug 2026 🏷️ Geral ✍️ Hermes Agent

O WhatsApp tornou-se o canal principal de comunicação para tudo: negócios, lembretes pessoais, apoio ao cliente e gestão de equipas. No entanto, responder manualmente às mesmas perguntas ou enviar lembretes um a um consome imenso tempo precioso do seu dia.

É aqui que entra o Hermes Agent. Graças à sua arquitetura flexível baseada em skills (competências) e integração com modelos de Inteligência Artificial, o Hermes Agent permite criar automações inteligentes no WhatsApp de forma rápida e sem complicações. Neste guia, vai aprender a configurar o Hermes Agent para gerir respostas automáticas, lembretes de compromissos e mensagens agendadas.

Porquê utilizar o Hermes Agent para o WhatsApp?

Diferente dos robôs tradicionais rígidos, o Hermes Agent combina a execução de comandos práticos com o poder dos LLMs (como GPT-4o, Claude ou modelos locais via Ollama). Isto traz várias vantagens:

  • Respostas contextuais: Em vez de mensagens robóticas, o agent compreende a dúvida do cliente e responde de forma natural.
  • Total controlo de agendamento: Programe avisos, lembretes e sequências de mensagens no horário exato.
  • Privacidade e flexibilidade: Pode usar o fornecedor de IA que preferir, incluindo modelos locais para proteger dados sensíveis.

Como ligar o WhatsApp no Hermes Agent

No Hermes Agent atual, o WhatsApp liga-se de duas formas: (1) pelo gateway usando a WhatsApp Cloud API oficial da Meta (recomendado para negócios), ou (2) pela bridge pessoal via hermes whatsapp. Neste guia usamos o gateway, que dá origem a uma sessão de mensagens como o Telegram.

Preparação

Antes de enviar mensagens precisas de um número da WhatsApp Cloud API ativo (criado no painel da Meta) e dos seguintes valores guardados no ficheiro ~/.hermes/.env:

WHATSAPP_CLOUD_PHONE_NUMBER_ID=123456789012345
WHATSAPP_CLOUD_ACCESS_TOKEN=EAAG...token...do-servico

Depois liga o WhatsApp no gateway:

hermes gateway setup        # escolher "whatsapp" e preencher os dados acima

3 Casos Práticos de Automação no WhatsApp

1. Respostas Automáticas para Perguntas Frequentes (FAQ)

Se recebe frequentemente mensagens a perguntar sobre horários de funcionamento, morada ou preços, pode configurar o Hermes Agent para analisar a mensagem recebida e gerar a resposta adequada instantaneamente. Com o gateway ativo, o agente recebe a mensagem e responde sozinho, em linguagem natural.

Para afinar o tom das respostas, cria uma skill em ~/.hermes/skills/whatsapp-atendimento/SKILL.md:

---
name: whatsapp-atendimento
description: Responde a clientes no WhatsApp com um tom profissional mas próximo, em português de Portugal.
version: 1.0.0
author: Hermes Agent
---

# Atendimento WhatsApp

## When to Use
Quando o gateway WhatsApp recebe uma mensagem de cliente.

## Instruções
1. Identifica a intenção (pergunta, reclamação, pedido).
2. Responde em português de Portugal, de forma clara e amigável.
3. Se for uma pergunta de preço/horário, responde com os dados conhecidos.

Podes também pedir diretamente no chat, sem skill, quando o gateway estiver ativo:

hermes chat -q "Responde ao cliente do WhatsApp a perguntar qual é o vosso horário ao fim de semana" -s whatsapp-atendimento

2. Lembretes Automáticos de Consultas ou Reuniões

A taxa de não comparência a reuniões e consultas diminui drasticamente quando é enviado um lembrete no próprio dia ou na véspera. Com o agendador nativo do Hermes, podes enviar um lembrete a horas certas:

# Envia todos os dias às 09:00 um lembrete para o número indicado
hermes cron create --name "lembrete-reuniao" --deliver whatsapp "0 9 * * *" "Lembrete: A sua reunião está agendada para hoje às 14:30."

3. Agendamento de Mensagens e Comunicações em Massa

Precisa de enviar uma novidade à sua equipa ou clientes na próxima segunda-feira às 09:00, mas não estará disponível nesse momento? Configure o parâmetro schedule_time no Hermes Agent para programar o envio prévio.

# Agendar uma comunicação para a equipa na próxima segunda-feira às 09:00
hermes cron create --name "aviso-manutencao" --deliver whatsapp "0 9 * * 1" "Aviso à equipa: a nossa plataforma estará em manutenção hoje às 22:00."

Boas Práticas para Evitar Bloqueios no WhatsApp

Quando automatiza mensagens no WhatsApp, é crucial manter comportamentos humanos para evitar suspensões de conta:

  1. Evite envios massivos simultâneos: Adicione pequenos intervalos (delays) entre as mensagens.
  2. Utilize a IA para variar o texto: Garanta que a IA reformula ligeiramente cada mensagem para evitar que o WhatsApp identifique o texto como spam repetitivo.
  3. Respeite a privacidade: Obtenha o consentimento dos destinatários antes de iniciar o contacto comercial.
