Cria o teu primeiro assistente de estudo com Hermes Agent

📅 29 Jul 2026 🏷️ Ensino Médio ✍️ Hermes Agent

Imagina teres um explicador particular disponível 24 horas por dia, 7 dias por semana, totalmente focado no teu ritmo de aprendizagem. Alguém que não se importa de te explicar a mesma fórmula de matemática três vezes, que resume a matéria de história para o teste de amanhã e que te explica conceitos complexos de ciências com analogias simples do dia a dia.

Com o Hermes Agent, isso não é apenas possível — é incrivelmente simples de criar. Se andas no ensino secundário/médio e queres usar a inteligência artificial para estudar melhor (e não apenas para copiar respostas), este tutorial é para ti.

Este tutorial mostra-te como criar a tua primeira skill de estudo personalizada no Hermes Agent em menos de 10 minutos.

---

O que é o Hermes Agent e por que motivo deves usá-lo?

O Hermes Agent é uma ferramenta open-source que te permite criar "agentes" e "skills" (competências) de inteligência artificial. Em vez de usares um chatbot genérico que por vezes dá respostas longas e confusas, o Hermes Agent permite-te configurar uma IA especializada com regras bem definidas.

Para um estudante, as vantagens são enormes:

  • Respostas focadas: O assistente responde exatamente no formato que te ajuda a aprender.
  • Privacidade e controlo: Podes usar modelos na nuvem (como OpenAI ou Claude) ou correr modelos totalmente locais no teu computador (via Ollama).
  • Gratuito e leve: Funciona diretamente no teu terminal ou linha de comandos.
---

Passo 1: Instalação Rápida do Hermes Agent

Para começares, precisas de ter o Hermes Agent instalado no teu computador (funciona em Windows, macOS e Linux). Abre o teu terminal e executa a instalação simples:

# Instalar o Hermes Agent (macOS)
brew install hermes-agent

# Verificar se a instalação correu bem
hermes --version

Nota: No Windows e no Linux, o processo é igualmente simples — consulta o guia Como Instalar o Hermes Agent para os comandos exatos do teu sistema. Se nunca usaste o terminal, não te preocupes! O processo é direto e só precisas de colar os comandos.

---

Passo 2: Criar a Skill "Assistente de Estudo"

No Hermes Agent, uma skill é um ficheiro de configuração simples (em formato YAML) onde ensinas a IA a comportar-se. Vamos criar uma skill dedicada às tuas disciplinas principais: Matemática, Ciências e História.

Cria um ficheiro chamado assistente_estudo.yaml na tua pasta de skills do Hermes (geralmente em ~/.hermes/skills/):

name: assistente_estudo
description: Assistente de estudo pessoal para matemática, ciências e história.
version: "1.0"
author: "Teu Nome"

prompt: |
  És o "TutorIA", um assistente de estudo amigável, paciente e entusiasmado para alunos do ensino secundário/médio.

  A tua missão é ajudar o aluno a APREENDER e não apenas dar a resposta final.

  DIRETRIZES POR DISCIPLINA:
  1. MATEMÁTICA:
     - NUNCA dês apenas o resultado final.
     - Explica a resolução passo a passo.
     - Destaca qual a regra ou fórmula utilizada em cada etapa.

  2. CIÊNCIAS (Biologia, Física, Química):
     - Explica conceitos complexos usando analogias do dia a dia.
     - Usa esquemas em texto ou tópicos simples para explicar processos (ex: fotossíntese, ciclo da água).

  3. HISTÓRIA:
     - Organiza os acontecimentos por ordem cronológica.
     - Destaca sempre: Causas, Acontecimento Principal e Consequências.
     - Relaciona o passado com o mundo atual quando possível.

  REGRAS GERAIS:
  - Usa um tom jovem, encorajador e direto ao ponto.
  - Usa marcadores (bullet points) para tornar a leitura leve no ecrã.
  - No final de cada explicação, faz 1 pergunta rápida de verificação para testar se o aluno percebeu.
---

Passo 3: Testar o teu Assistente na Prática

Com o ficheiro guardado, estás pronto para arrancar! Abre o terminal e inicia o chat interativo com a tua nova skill:

hermes chat --skill assistente_estudo

Vejamos alguns exemplos do que podes perguntar ao teu novo assistente:

Exemplo 1: Matemática

Tu: "Não consigo resolver esta equação: 3x + 12 = 27. Como faço?"

TutorIA: Raciocina contigo, isolando a incógnita $x$ passo a passo, explicando que o $12$ passa para o outro lado a subtrair, antes de dividir por $3$. No final, pergunta-te: "Se a equação fosse 2x + 5 = 15, qual seria o primeiro passo?"

Exemplo 2: Ciências

Tu: "O que é a osmose? Tenho teste amanhã e não entendo o livro."

TutorIA: Explica a osmose com a analogia de uma festa cheia de gente a mover-se para uma sala com mais espaço, mostrando o movimento da água do meio menos concentrado para o mais concentrado através de uma membrana.

Exemplo 3: História

Tu: "Faz-me um resumo rápido sobre a Revolução Industrial para eu rever."

TutorIA: Entrega-te um resumo em 3 secções simples: Causas (máquina a vapor, êxodo rural), O Evento (transição do trabalho manual para fábricas) e Consequências (crescimento das cidades, novas classes sociais).

---

Dicas Extra para Tirares o Máximo Partido

  1. Pede mapas mentais: Podes pedir ao assistente: "Cria uma lista em texto estruturada para eu transformar num mapa mental no meu caderno."
  2. Simula testes: Escreve "Faz-me 5 perguntas de escolha múltipla sobre a célula eucariótica e avalia as minhas respostas no final."
  3. Muda o modelo de IA: Se precisares de raciocínio matemático mais avançado, podes configurar o Hermes Agent para usar modelos como o Claude 3.5 Sonnet ou GPT-4o.
