Automatizar o Telegram de uma empresa com Hermes Agent

📅 17 Aug 2026 📖 5 min de leitura 🏷️ Empresas ✍️ Marcus

Copiar e colar novidades, responder às mesmas perguntas dos clientes ou partilhar relatórios internos de forma manual são tarefas que consomem horas preciosas da tua equipa. Gerir a comunicação de uma empresa ou de uma loja digital exige agilidade, e cada minuto gasto em trabalho repetitivo é tempo que falta para decisões importantes. É aqui que entra o Hermes Agent, um assistente de Inteligência Artificial open-source concebido para correr localmente ou na cloud e automatizar fluxos de trabalho complexos de forma extremamente simples.

Porquê utilizar o Hermes Agent para automatizar o Telegram?

O Telegram é uma das plataformas de comunicação mais robustas do mercado, muito utilizada por micro e grandes empresas para criar canais de transmissão de novidades, grupos de apoio ao cliente e chats de coordenação interna. Ao integrar o Hermes Agent com o Telegram, transformas um canal de chat passivo num ecossistema inteligente capaz de interpretar dados, gerar publicações apelativas e responder a utilizadores automaticamente sem intervenção humana constante.

Guia Prático: Configurar a Automação do Telegram com Hermes Agent

Vamos criar uma automação passo a passo para enviar comunicados formatados com IA para um canal ou grupo do Telegram da tua empresa.

Passo 1: Instalar o Hermes Agent

O primeiro passo é garantir que tens o Hermes Agent instalado no teu sistema operativo. Abre o teu terminal e executa o comando correspondente à tua plataforma:

# Para utilizadores de macOS e Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Para utilizadores de Windows (executar no PowerShell como Administrador)
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Este comando descarrega o script de instalação oficial do Hermes Agent, configura as dependências necessárias no teu sistema e adiciona a ferramenta de linha de comandos (CLI) ao teu terminal para que possas correr os teus agentes de imediato.

Passo 2: Criar a Skill de Automação em Markdown (SKILL.md)

As automações no Hermes Agent são definidas através de ficheiros Markdown chamados Skills. Cria uma pasta chamada publicador-telegram dentro do diretório de skills do Hermes e, dentro dela, um ficheiro chamado SKILL.md (ou seja, ~/.hermes/skills/publicador-telegram/SKILL.md) com a estrutura canónica indicada abaixo:

---
name: publicador-telegram
description: Automatiza o envio de comunicados, novidades e relatórios para canais e grupos do Telegram usando a API do Telegram.
author: MarctechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [telegram, automacao, empresas]
---

# publicador-telegram
Esta skill permite que o Hermes Agent formate e envie mensagens estruturadas para o Telegram de forma automática.

## When to Use
Usa esta skill sempre que precisares de enviar comunicados de imprensa, atualizações de produtos, novidades de stock ou relatórios internos para um canal ou grupo específico do Telegram.

## Instruções
1. Solicita ao utilizador o texto base ou o relatório que precisa de ser enviado.
2. Melhora a formatação do texto, adicionando emojis relevantes e organizando o conteúdo em pontos legíveis.
3. Utiliza as variáveis de ambiente TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID configuradas no sistema.
4. Executa um pedido HTTP POST para a API do Telegram (https://api.telegram.org/bot<token>/sendMessage) com o texto formatado.
5. Confirma se o envio foi bem-sucedido e apresenta o resultado ao utilizador.

## Critérios de conclusão
- A mensagem foi enviada com sucesso para o ID do chat configurado.
- O utilizador recebe uma confirmação visual no terminal com o estado do envio.

Este ficheiro de skill indica ao Hermes as metainformações necessárias (no bloco de metadados em YAML) e orienta o modelo de linguagem sobre as regras de execução, o formato da mensagem e o destino do envio através da API oficial do Telegram.

Passo 3: Configurar as Credenciais e Variáveis de Ambiente

Para que o Hermes Agent consiga comunicar com o Telegram, precisas de criar um Bot através do BotFather no Telegram para obter o teu Token de API e o ID do canal ou grupo. Depois, exporta essas variáveis no teu terminal:

# Em macOS e Linux
export TELEGRAM_BOT_TOKEN="o_teu_token_aqui"
export TELEGRAM_CHAT_ID="o_id_do_teu_canal_ou_grupo"

# Em Windows (PowerShell)
$env:TELEGRAM_BOT_TOKEN="o_teu_token_aqui"
$env:TELEGRAM_CHAT_ID="o_id_do_teu_canal_ou_grupo"

Estas variáveis de ambiente garantem que as chaves de acesso confidenciais da tua empresa não ficam expostas diretamente no código da skill, respeitando as melhores práticas de segurança e isolamento de credenciais do Hermes Agent.

Passo 4: Listar e Executar a Skill com o Hermes Agent

Agora que a skill está configurada no diretório correto, podes verificar se o Hermes a reconhece e executá-la de forma interativa:

# Verificar se a skill está na lista ativa
hermes skills list

# Executar a skill no modo de chat interativo
hermes chat -s publicador-telegram

O comando hermes skills list mostra todas as skills ativas no sistema. Ao correr hermes chat -s publicador-telegram, inicias uma sessão de chat em que o Hermes Agent assume o papel de publicador, solicita a informação que queres enviar, formata-a com IA e realiza o envio automático para o Telegram.

Casos de Uso Reais para Empresas e Lojas

A flexibilidade do Hermes Agent permite ir muito além do envio de simples mensagens. Eis como diferentes tipos de negócios podem tirar partido desta tecnologia:

  • Lojas Online (E-commerce): Automatização do envio de novidades de stock ou promoções relâmpago diretamente para um canal de clientes, com textos persuasivos gerados pela IA com base em dados de produtos.
  • Atendimento ao Cliente: Ligação do Hermes Agent a um grupo de suporte do Telegram, onde o agente lê as dúvidas dos clientes e responde de forma autónoma com base em documentos de FAQ da empresa.
  • Relatórios e Integrações Internas: Programação do Hermes para ler um ficheiro CSV ou Excel de vendas diárias e publicar um resumo visual detalhado no grupo de direção da empresa.

Conclusão

Automatizar o Telegram da tua empresa com o Hermes Agent poupa tempo, elimina erros manuais e garante uma comunicação consistente e profissional com clientes e equipas internas. Ao utilizar skills estruturadas em Markdown, ganhas controlo total sobre como a IA interage com as tuas ferramentas de trabalho diárias.
