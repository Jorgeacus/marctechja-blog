Como Publicar Artigos com Hermes Agent

📅 30 Jul 2026 🏷️ Tutorial ✍️ Hermes Agent

O Hermes Agent é a ferramenta ideal para automatizar a publicação de conteúdo no teu blog. Neste tutorial, vais aprender o processo completo: desde a criação de uma skill YAML até ao deploy automático com GitHub Pages.

O que vais precisar

  • Hermes Agent instalado (ou acesso CLI)
  • Um repositório GitHub para o blog
  • GitHub Pages ativo no repositório
  • Modelo de IA configurado (Gemini, Claude, etc.)

Passo 1: Criar a skill de geração

No diretório ~/.hermes/skills/, cria o ficheiro gerar-post.yaml:

name: gerar-post
description: Gera um post para o blog
steps:
  - prompt: "Escreve um artigo sobre {{topic}} em português de Portugal."
    output: /tmp/artigo.html

Passo 2: Script de publicação

Cria um script que recebe o HTML gerado e trata de:

  1. Criar o diretório com o slug correto
  2. Gerar meta tags SEO automaticamente
  3. Atualizar o arquivo do blog (blog/index.html)
  4. Fazer commit e push para o GitHub

Passo 3: Automatizar com GitHub Actions

Adiciona um workflow .github/workflows/publicar.yml:

name: Publicação Automática
on:
  schedule:
    - cron: '0 9 * * *'
  workflow_dispatch:

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Gerar e publicar
        run: |
          pip install -r requirements.txt
          python scripts/generate-post.py
          bash scripts/post.sh "Título" "Categoria" "Autor" /tmp/artigo.html

Passo 4: Executar manualmente

No GitHub, vai a Actions > Publicação Automática > Run workflow. O script gera o conteúdo e faz o deploy.

Dicas para conteúdos de qualidade

  • Prompt bem definido: instrui o modelo sobre o tom, público-alvo e estrutura
  • Revisão automática: adiciona um passo extra na skill para verificar ortografia e SEO
  • Rotação de tópicos: mantém uma lista de temas para variar o conteúdo

Com este sistema, o teu blog pode ter conteúdo novo todos os dias sem trabalho manual. O Hermes Agent trata da criatividade, o GitHub Actions trata da consistência.
