Enviar áudio e imagens automáticos no WhatsApp com Hermes Agent

📅 07 Aug 2026 🏷️ Geral ✍️ Hermes Agent

Imagina que podes enviar um áudio personalizado, com uma voz humana gerada por Inteligência Artificial, e uma imagem de alta qualidade para o WhatsApp de um cliente, de forma 100% automática, sem sequer tocares no teu telemóvel. Parece ficção científica? Com o Hermes Agent, esta é a realidade atual de milhares de profissionais e empresas que estão a revolucionar a sua produtividade e a comunicação com os seus clientes.

Porquê Automatizar o WhatsApp com o Hermes Agent?

O WhatsApp é o canal de comunicação com maior taxa de abertura do mundo. No entanto, enviar mensagens manuais para dezenas ou centenas de contactos consome imenso tempo. Pior: mensagens puramente de texto muitas vezes são ignoradas. O envio de imagens dinâmicas e áudios personalizados gera muito mais proximidade, confiança e conversão.

Com o Hermes Agent, podes criar "skills" (competências) em ficheiros YAML simples que instruem a IA a gerar conteúdo de voz natural e a enviá-lo juntamente com ficheiros multimédia de forma totalmente autónoma.

Configuração Passo a Passo: Enviar Áudio e Imagem com IA

Vamos configurar uma automação prática e funcional. Segue os passos abaixo para criares a tua primeira skill de envio multimédia.

Passo 1: Instalação do Hermes Agent

Para começar, precisas de ter o Hermes Agent instalado na tua máquina. Se utilizas o macOS, podes instalá-lo rapidamente através do terminal utilizando o Homebrew:

brew install hermes-agent

Se utilizas Linux ou Windows, deves consultar as instruções detalhadas de instalação no guia oficial para configurar as tuas variáveis de ambiente e dependências do sistema.

Passo 2: Criar a Skill Personalizada (YAML)

As automações do Hermes Agent são estruturadas em ficheiros YAML limpos e legíveis. Cria um ficheiro chamado enviar_multimedia.yaml dentro do teu diretório de skills (normalmente localizado em ~/.hermes/skills/) e adiciona o seguinte código:

name: enviar_multimedia
description: Automatiza o envio de áudios gerados por IA e imagens personalizadas no WhatsApp.
author: MarcTechJA
version: "1.0"
inputs:
  phone_number: { type: string, description: "Número de telemóvel do destinatário com indicativo (ex: +351912345678)", required: true }
  image_url: { type: string, description: "URL da imagem que pretendes enviar", required: true }
  audio_text: { type: string, description: "Texto que a IA vai converter em áudio de voz", required: true }
steps:
  - name: generate_speech
    action: llm.generate
    params:
      prompt: "Lê o seguinte texto de forma calorosa, profissional e natural para gravação de voz: { inputs.audio_text }"
  - name: send_audio
    action: tools.whatsapp.send
    params:
      to: "{ inputs.phone_number }"
      type: "audio"
      content: "{ steps.generate_speech.output }"
  - name: send_image
    action: tools.whatsapp.send
    params:
      to: "{ inputs.phone_number }"
      type: "image"
      content: "{ inputs.image_url }"
outputs:
  status: "O áudio e a imagem foram enviados com sucesso para { inputs.phone_number }."

O que faz este código?

  • inputs: Define os parâmetros necessários para a execução (número do destinatário, link da imagem e o texto que será falado).
  • steps.generate_speech: Utiliza o motor de IA configurado no teu Hermes Agent (como a API da OpenAI, Gemini ou um modelo local via Ollama) para sintetizar o texto num áudio de voz realista.
  • steps.send_audio & steps.send_image: Utilizam a ferramenta integrada do WhatsApp do Hermes Agent para disparar o áudio gerado e a imagem fornecida diretamente para o número de destino.

Passo 3: Executar a Skill no Terminal

Com a skill configurada e guardada na pasta correta, podes executá-la instantaneamente através de um único comando no teu terminal:

hermes run enviar_multimedia --phone_number "+351912345678" --image_url "https://python.org/static/img/python-logo.png" --audio_text "Olá! Passava por aqui para confirmar que o teu relatório de automação está pronto. Podes ver o gráfico na imagem anexa."

Ao premires Enter, o Hermes Agent irá processar o texto, convertê-lo em áudio através de IA, aceder ao teu canal do WhatsApp e entregar ambas as mensagens ao destinatário em poucos segundos.

Casos Práticos de Aplicação no Dia a Dia

Esta poderosa combinação de áudio por IA e imagem abre portas a infinitas possibilidades de automação empresarial e pessoal:

  • Recuperação de Carrinhos Abandonados: Envia uma imagem do produto esquecido no teu e-commerce acompanhada de um áudio simpático do teu "assistente virtual" a oferecer um cupão de desconto exclusivo.
  • Lembretes de Consultas e Reservas: Clínicas, ginásios ou restaurantes podem programar o envio de um áudio personalizado com o nome do cliente e uma imagem do mapa ou QR Code de confirmação.
  • Suporte ao Cliente Escalável: Responde a dúvidas frequentes enviando capturas de ecrã explicativas acompanhadas de um áudio passo a passo, poupando horas de trabalho à tua equipa de suporte.

Conclusão: O Futuro da Automação Está ao Teu Alcance

Automatizar o WhatsApp com o Hermes Agent vai muito além do simples envio de mensagens de texto automáticas. Ao integrares inteligência artificial para gerar áudios dinâmicos e anexar imagens contextuais, consegues humanizar a comunicação à escala global, sem perder o toque pessoal que converte contactos em clientes satisfeitos.
