Python para automação: por onde começar

📅 18 Aug 2026 🏷️ Programadores ✍️ Hermes Agent

Sentes que passas horas a realizar tarefas repetitivas no computador, como organizar pastas, descarregar ficheiros ou copiar dados de um lado para o outro? A boa notícia é que podes colocar o teu computador a trabalhar por ti. O Python é a linguagem ideal para dar os primeiros passos no mundo da automação, permitindo transformar processos manuais demorados em scripts simples que correm em segundos.

Por que escolher o Python para automação?

O Python tornou-se a linguagem padrão para automação devido a três fatores fundamentais: uma sintaxe clara e legível (que se assemelha a inglês simples), uma comunidade gigantesca e um ecossistema rico em bibliotecas prontas a usar. Com poucas linhas de código, é possível interagir com o sistema operativo, fazer pedidos à web ou agendar tarefas para executarem autonomamente.

Passo 1: Instalar o Python e preparar o ambiente

Antes de escrever o primeiro script, precisas de ter o Python instalado no teu sistema. A maioria dos sistemas operativos modernos (macOS e Linux) já traz o Python pré-instalado, mas podes obter a versão mais recente diretamente do site oficial.

# Verificação da instalação no terminal ou linha de comandos
python3 --version

# Instalação das bibliotecas necessárias para os exemplos
pip install requests schedule

O que o código faz: O primeiro comando verifica se o Python está devidamente instalado e exibe a versão atual no terminal. O segundo comando utiliza o gestor de pacotes do Python (pip) para instalar as bibliotecas externas requests e schedule, que usaremos nos passos seguintes.

Passo 2: Manipulação do sistema de ficheiros com a biblioteca `os`

A biblioteca os (e a sua parceira shutil) faz parte da biblioteca padrão do Python, o que significa que não requer instalação adicional. É perfeita para automatizar tarefas como criar pastas, renomear ficheiros e organizar diretórios organizando ficheiros por extensão.

import os
import shutil

# Passo de automação: mover ficheiros PDF para uma pasta específica
pasta_origem = "./meus_documentos"
pasta_destino = "./meus_documentos/PDFs"

# Criar a pasta de destino se não existir
if not os.path.exists(pasta_destino):
    os.makedirs(pasta_destino)

# Listar e mover ficheiros
if os.path.exists(pasta_origem):
    for ficheiro in os.listdir(pasta_origem):
        if ficheiro.endswith(".pdf"):
            caminho_antigo = os.path.join(pasta_origem, ficheiro)
            caminho_novo = os.path.join(pasta_destino, ficheiro)
            shutil.move(caminho_antigo, caminho_novo)
            print(f"Ficheiro movido com sucesso: {ficheiro}")

O que o código faz: O script inspeciona uma pasta especificada, procura todos os ficheiros com a extensão .pdf, cria uma subpasta dedicada caso esta ainda não exista e move cada ficheiro encontrado automaticamente para o novo local.

Passo 3: Consumo de dados e APIs com a biblioteca `requests`

A automação moderna envolve frequentemente a recolha de informação na internet. A biblioteca requests permite fazer pedidos HTTP de forma extremamente simples para consumir dados de APIs REST ou descarregar conteúdos web.

import requests

# Consultar uma API pública para obter o estado de um serviço
url = "https://api.github.com/zen"

resposta = requests.get(url)

if resposta.status_code == 200:
    print("Conexão bem-sucedida!")
    print(f"Mensagem recebida: {resposta.text}")
else:
    print(f"Ocorreu um erro no pedido. Código de estado: {resposta.status_code}")

O que o código faz: O script envia um pedido GET para um servidor remoto, valida se a resposta foi bem-sucedida (código 200) e imprime a mensagem recebida no ecrã. Este padrão é a base para automatizar a leitura de dados financeiros, previsões meteorológicas ou notificações.

Passo 4: Agendamento automático com a biblioteca `schedule`

De que serve um script de automação se tiveres de o executar manualmente todos os dias? A biblioteca schedule permite definir tarefas agendadas em sintaxe legível e humana.

import schedule
import time

def verificar_tarefas():
    print("Execução agendada: A verificar novos ficheiros e atualizações...")

# Agendar a função para ser executada a cada 10 segundos (para teste)
schedule.every(10).seconds.do(verificar_tarefas)

print("Agendador em execução. Pressiona Ctrl+C para parar.")

while True:
    schedule.run_pending()
    time.sleep(1)

O que o código faz: O script cria um ciclo contínuo em segundo plano que verifica se há tarefas pendentes e executa a função verificar_tarefas exatamente nos intervalos definidos (neste caso, a cada 10 segundos, mas poderia ser a cada hora ou todos os dias a uma hora específica).

Os scripts Python tradicionais são excelentes para tarefas estruturadas, mas e se precisares de tomar decisões complexas, analisar texto não estruturado ou interagir com múltiplos fornecedores de IA? É aqui que entra o Hermes Agent.

O Hermes Agent permite estender os teus scripts com capacidades avançadas de IA organizadas em Skills (competências). Podes instalar o Hermes Agent no teu sistema com um único comando no terminal:

# Instalação do Hermes Agent em macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Para criar uma automação inteligente com o Hermes Agent, podes definir uma skill personalizada. Cria uma pasta chamada organizador-inteligente dentro do diretório de skills do Hermes e, dentro dela, um ficheiro chamado SKILL.md (ou seja, ~/.hermes/skills/organizador-inteligente/SKILL.md) com o seguinte conteúdo:

---
name: organizador-inteligente
description: Analisa e categoriza documentos automaticamente com base no seu conteúdo.
author: MarctechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [python, automacao, ia]
---

# organizador-inteligente
Skill para analisar documentos de texto e organizá-los por tema usando inteligência artificial.

## When to Use
Utilize esta skill sempre que precisar de processar uma lista de ficheiros de texto e classificá-los automaticamente.

## Instruções
1. Identifica os ficheiros de texto presentes na pasta de trabalho.
2. Lê o conteúdo de cada ficheiro e determina a sua categoria principal (ex: Finanças, Pessoal, Trabalho).
3. Move cada ficheiro para a pasta correspondente à categoria identificada.

## Critérios de conclusão
- Todos os ficheiros de texto são movidos para pastas organizadas por tema sem perdas de informação.

Para listar as tuas skills e executar esta automação baseada em IA no Hermes Agent, utiliza os comandos:

# Listar skills disponíveis
hermes skills list

# Executar o chat interativo com a skill carregada
hermes chat -s organizador-inteligente

O que a skill faz: Em vez de depender apenas de extensões de ficheiros como no script Python simples, o Hermes Agent lê o conteúdo real de cada documento e utiliza modelos de IA para decidir inteligentemente onde arquivar cada ficheiro.
