Criar um site com Python e publicar de graça

📅 12 Aug 2026 🏷️ Programadores ✍️ Hermes Agent

Imagina poderes criar a tua própria página web do zero, utilizando a simplicidade do Python, e colocá-la online totalmente grátis em questão de minutos. Quer queiras criar um portfólio pessoal, um site para o teu projeto ou simplesmente aprender a programar, publicar o teu trabalho na internet é hoje mais fácil do que nunca — especialmente quando juntas o poder do Python à automação inteligente com o Hermes Agent.

O que vais precisar para começar

Para construir e publicar o teu site sem gastar um único cêntimo, vais utilizar ferramentas acessíveis e amplamente adotadas na indústria de software:

  • Python: A linguagem de programação principal para estruturar a tua aplicação ou gerar as tuas páginas.
  • Flask: Uma micro-framework Python leve e extremamente simples para criar aplicações web.
  • GitHub / GitHub Pages ou Render: Plataformas gratuitas para alojar o teu código e disponibilizar a tua página para todo o mundo.
  • Hermes Agent: O assistente de IA que podes utilizar para gerar código HTML, configurar estruturas de ficheiros e automatizar todo o processo de desenvolvimento.

Passo 1: Configurar o ambiente e criar a aplicação Python

Neste primeiro passo, vamos criar a estrutura básica da nossa aplicação em Python utilizando a micro-framework Flask. O Flask permite definir rotas de forma rápida e servir ficheiros HTML com poucas linhas de código.

Abre o teu terminal ou ambiente de desenvolvimento e cria um ficheiro chamado app.py com o seguinte código:

from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    return render_template('index.html')

if __name__ == '__main__':
    app.run(debug=True)

O que faz este código: Importamos a biblioteca Flask e a função render_template. Definimos a rota principal ('/') que, ao ser acedida no navegador, carrega e exibe o ficheiro index.html contido na pasta de modelos (templates).

Passo 2: Criar a página HTML do site

Agora precisamos do ficheiro visual que o utilizador vai ver. Cria uma pasta chamada templates no mesmo diretório do teu ficheiro app.py e, dentro dela, cria o ficheiro index.html.

<!DOCTYPE html>
<html lang="pt-PT">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>O Meu Primeiro Site em Python</title>
    <style>
        body { font-family: Arial, sans-serif; text-align: center; padding: 50px; background-color: #f4f4f9; }
        h1 { color: #333; }
        p { color: #666; font-size: 1.2rem; }
        .card { background: white; padding: 20px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.1); display: inline-block; }
    </style>
</head>
<body>
    <div class="card">
        <h1>Bem-vindo ao Meu Site!</h1>
        <p>Este site foi construído com Python e publicado gratuitamente.</p>
    </div>
</body>
</html>

O que faz este código: Este documento define a estrutura estática da página web, incluindo um cabeçalho, um parágrafo explicativo e estilos CSS simples para garantir uma apresentação limpa e moderna em qualquer ecrã.

Passo 3: Automatizar a criação e atualização com o Hermes Agent

Se quiseres acelerar a criação de novas páginas, podes utilizar o Hermes Agent para gerar automaticamente o conteúdo do site através de uma custom skill personalizada. O Hermes Agent permite-te definir fluxos de trabalho inteligentes que escrevem ficheiros diretamente no teu projeto.

Abaixo está um exemplo real de uma skill YAML do Hermes Agent para criar páginas HTML adicionais de forma automática:

name: gerador_pagina_site
description: Gera automaticamente um ficheiro HTML simples para o site em Python
author: MarcTechJA
version: "1.0"

inputs:
  titulo_pagina:
    type: string
    description: O título principal da nova página web
    required: true
  conteudo_texto:
    type: string
    description: O texto explicativo que vai aparecer na página
    required: true

steps:
  - name: construir_html
    action: llm.generate
    params:
      prompt: "Cria um ficheiro HTML5 limpo com o título '{ inputs.titulo_pagina }' e o conteúdo: '{ inputs.conteudo_texto }'. Utiliza estilos CSS integrados e modernos."

  - name: guardar_ficheiro
    action: tools.file.write
    params:
      path: "templates/pagina.html"
      content: "{ steps.construir_html.output }"

outputs:
  resultado: "Página criada com sucesso na pasta templates/pagina.html"

O que faz esta skill: A skill recebe o título e o conteúdo desejado, aciona o modelo de linguagem para estruturar o código HTML completo e guarda o resultado diretamente no ficheiro templates/pagina.html dentro do teu projeto Python.

Passo 4: Publicar o teu site gratuitamente online

Com o projeto pronto, podes torná-lo acessível a qualquer pessoa na internet de duas formas gratuitas e populares:

  1. Render / PythonAnywhere (para sites dinâmicos em Flask):
    • Cria uma conta gratuita no Render ou PythonAnywhere.
    • Envia o teu projeto para um repositório no GitHub.
    • Conecta o teu repositório à plataforma de alojamento e define o comando de arranque como python app.py ou gunicorn app:app. O teu site estará online num URL .onrender.com em poucos minutos.
  2. GitHub Pages (para páginas estáticas):
    • Se converteres o teu projeto Python num gerador de páginas estáticas (exportando o ficheiro HTML), podes colocá-lo no GitHub.
    • Acede às definições (Settings) do teu repositório no GitHub, ativa o GitHub Pages na branch principal e o teu site ficará imediatamente disponível de forma gratuita sob o domínio seu-usuario.github.io.

Conclusão

Criar e publicar um site com Python não precisa de ser um processo dispendioso ou complexo. Ao combinar a flexibilidade do Flask, a gratuitidade de plataformas como o GitHub Pages ou Render, e a capacidade de automação do Hermes Agent, podes tirar as tuas ideias do papel e colocá-las no ar numa questão de minutos.

O próximo passo é explorar novas funcionalidades, como adicionar formulários de contacto, bases de dados simples ou integrar agentes de IA que mantêm o teu conteúdo sempre atualizado.
