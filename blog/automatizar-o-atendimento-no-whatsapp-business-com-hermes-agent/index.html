Automatizar o atendimento no WhatsApp Business com Hermes Agent

📅 05 Aug 2026 🏷️ Empresas ✍️ Hermes Agent

Sentes que a tua empresa perde potenciais vendas simplesmente porque não consegue responder a tempo a todas as mensagens no WhatsApp Business? No mercado atual, tanto para uma pequena loja de bairro como para uma grande empresa, a rapidez na resposta é o fator decisivo entre fechar um negócio ou perder o cliente para a concorrência. A boa notícia é que podes automatizar todo este processo — desde saudações iniciais e respostas a dúvidas frequentes até ao envio de catálogos e lembretes — de forma inteligente com o Hermes Agent.

Porquê utilizar o Hermes Agent no WhatsApp Business?

Diferente dos robôs de atendimento tradicionais baseados em menus rígidos ("digite 1 para vendas, 2 para suporte"), o Hermes Agent utiliza modelos avançados de inteligência artificial (como GPT-4o, Claude ou DeepSeek) para compreender a linguagem natural do cliente. Isto significa que a tua empresa pode oferecer um atendimento humanizado, ágil e disponível 24 horas por dia, 7 dias por semana.

Com o Hermes Agent, podes automatizar:

  • Mensagens de boas-vindas: Receção imediata e personalizada para novos contactos.
  • FAQ inteligente: Respostas automáticas sobre horários, localização, métodos de pagamento e políticas de devolução.
  • Envio de catálogo: Disponibilização rápida dos teus produtos ou serviços em resposta a pedidos específicos.
  • Lembretes e acompanhamento: Confirmação de agendamentos, reservas ou estado de encomendas.

Guia Prático: Configurar o Atendimento Automatizado Passo a Passo

Para ilustrar como podes colocar esta automação a funcionar na tua empresa, preparámos um tutorial simples e direto utilizando as capacidades de skills do Hermes Agent.

Passo 1: Instalar o Hermes Agent e configurar o Provider de IA

O primeiro passo consiste na instalação do agente no teu ambiente de trabalho ou servidor. O método oficial é o instalador de linha de comandos (Linux e macOS); no Windows usa o instalador nativo do PowerShell.

# macOS e Linux — instalador oficial
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

# Definir o provider de IA (a chave fica em ~/.hermes/.env)
hermes setup

O que o código faz: Instala a CLI do Hermes Agent e abre o assistente de configuração, onde escolhes o provider de IA e a respetiva chave de API, que fica guardada em ~/.hermes/.env.

Passo 2: Ligar o WhatsApp Cloud API e criar a Skill de Atendimento

Para enviar e receber mensagens no WhatsApp Business, liga o WhatsApp Cloud API (o serviço oficial da Meta). Primeiro adiciona as tuas credenciais ao ~/.hermes/.env:

WHATSAPP_CLOUD_PHONE_NUMBER_ID=o_teu_phone_number_id
WHATSAPP_CLOUD_ACCESS_TOKEN=o_teu_token
WHATSAPP_ENABLED=true

Depois regista o gateway do WhatsApp e associa a tua conta:

hermes gateway setup        # escolhe WhatsApp quando pedido
hermes whatsapp-cloud        # confirma que o canal está ligado

No Hermes Agent, as automações são organizadas em ficheiros SKILL.md. Vamos criar uma skill dedicada ao atendimento ao cliente via WhatsApp em ~/.hermes/skills/whatsapp_atendimento/SKILL.md:

---
name: whatsapp_atendimento
description: Analisa a mensagem do cliente no WhatsApp Business e envia uma resposta personalizada baseada no catálogo e FAQs da empresa.
author: MarctechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [whatsapp, atendimento]
---

# whatsapp_atendimento

Atende clientes no WhatsApp Business com respostas personalizadas.

## When to Use
Quando chega uma mensagem de cliente no WhatsApp Business gerido pelo gateway do Hermes.

## Instruções
1. Lê a mensagem da pessoa que contactou a empresa no WhatsApp.
2. Um assistente virtual responde de forma cordial, profissional e direta à mensagem.
3. Se pedirem o catálogo, indica os produtos principais. Se a pergunta sair das FAQs, encaminha para um humano.
4. Mantém o tom acessível e em português de Portugal.

## Critérios de conclusão
- A resposta foi enviada de volta pelo canal do WhatsApp.
- Pedidos fora da base de conhecimento ficaram sinalizados para atendimento humano.

O que o código faz: A skill descreve o comportamento do agente para o atendimento: interpreta a mensagem do cliente, gera uma resposta adequada ao contexto do negócio e envia-a de volta pelo canal do WhatsApp ligado no gateway.

Passo 3: Executar e Testar a Automação

Com a skill guardada e o gateway ativo, podes testar num chat. Também podes agendar mensagens automáticas para clientes com o cron:

# Ver que a skill está disponível e testá-la
hermes skills list
hermes chat -s whatsapp_atendimento "Olá, qual é o vosso horário de funcionamento e como vejo o catálogo?"

# Agendar um lembrete automático entregue por WhatsApp
hermes cron create --name lembrete-visita --deliver whatsapp --skill whatsapp_atendimento "0 9 * * *" "Envia um lembrete amigável sobre a visita agendada de hoje"

O que o código faz: Primeiro testa a skill com uma pergunta real. Depois, o comando cron cria um agendamento diário às 09:00 que usa a skill para entregar uma mensagem automática pelo WhatsApp.

Boas Práticas para o Atendimento com IA no WhatsApp

Para garantir que a automação melhora a experiência do utilizador e não causa frustrações, considera as seguintes recomendações:

  1. Indica que o atendimento é automatizado: Os clientes apreciam a transparência. Uma breve nota como "Sou o assistente virtual da [Sua Empresa]" estabelece expetativas corretas.
  2. Disponibiliza um canal de transição para humanos: Garante que, em casos complexos ou reclamações, o agente consiga encaminhar o diálogo para um operador humano.
  3. Mantém a base de conhecimento atualizada: Atualiza os prompts e ficheiros de contexto da tua skill sempre que existirem alterações de preços, stocks ou horários.
  4. Garante a privacidade dos dados: Certifica-te de que o tratamento de contactos cumpre o RGPD e as boas práticas de segurança da tua empresa.
