Automatizar o Instagram de uma empresa com Hermes Agent

📅 16 Aug 2026 📖 7 min de leitura 🏷️ Empresas ✍️ Marcus

Planear o calendário editorial, escrever legendas criativas, pesquisar hashtags relevantes e responder a dezenas de mensagens diretas (DMs) — gerir o Instagram da tua empresa pode parecer um trabalho a tempo inteiro. Felizmente, com o avanço da Inteligência Artificial, já podes automatizar grande parte deste processo. O Hermes Agent é uma ferramenta de IA open-source que te permite criar agentes autónomos para gerir a presença digital da tua marca de forma eficiente, personalizada e totalmente automatizada.

O que é o Hermes Agent e como ajuda o teu negócio?

O Hermes Agent é um assistente baseado em IA que corre tanto na nuvem como no teu próprio computador (usando modelos locais como o Ollama). Para microempresas que não têm orçamento para uma agência de marketing, ou grandes lojas que precisam de escala, o Hermes Agent atua como um assistente de marketing virtual. Ele pode ser treinado com a identidade da tua marca para gerar ideias de conteúdo, escrever legendas com o teu tom de voz e até estruturar respostas automáticas para os teus clientes no Instagram.

Passo 1: Instalar o Hermes Agent no teu sistema

Antes de começarmos a automatizar o Instagram, precisamos de instalar o Hermes Agent na tua máquina de trabalho ou servidor. O processo é extremamente simples e pode ser feito através do terminal.

# Para utilizadores de macOS e Linux:
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Para utilizadores de Windows (executar no PowerShell como Administrador):
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Estes comandos descarregam e correm o instalador oficial do Hermes Agent diretamente no teu sistema operativo. Após a instalação, podes verificar se tudo está a funcionar corretamente digitando hermes --help no teu terminal para ver a lista de comandos disponíveis.

Passo 2: Criar a Skill de Geração de Conteúdo (SKILL.md)

No ecossistema do Hermes Agent, uma Skill é um conjunto de instruções estruturadas que ensina o agente a realizar uma tarefa específica. Vamos criar uma skill chamada instagram_generator que gera legendas cativantes e hashtags estratégicas com base no teu produto. Cria um ficheiro chamado SKILL.md dentro do diretório de skills do Hermes (geralmente localizado em ~/.hermes/skills/instagram_generator/SKILL.md).

---
name: instagram_generator
description: Gera legendas criativas e hashtags estratégicas para posts de Instagram de marcas e lojas.
author: MarctechJA
version: "1.0"
platforms:
  - macos
  - linux
  - windows
metadata:
  hermes:
    tags: [marketing, instagram, redes-sociais]
---

# instagram_generator
Esta skill transforma ideias de produtos ou promoções em publicações completas e otimizadas para o Instagram, adaptando-se ao tom de voz da marca.

## When to Use
Usa esta skill sempre que precisares de criar uma legenda para o Instagram, planear um carrossel de fotos, ou gerar hashtags relevantes para aumentar o alcance orgânico de uma publicação.

## Instruções
1. Identifica o produto, serviço ou tema principal do post fornecido pelo utilizador.
2. Define o tom de voz pretendido (ex: profissional, descontraído, divertido).
3. Cria uma estrutura de legenda com:
   - Um gancho (hook) forte na primeira linha para captar a atenção.
   - O corpo do texto focado nos benefícios e não apenas nas características do produto.
   - Uma chamada para ação clara (Call to Action - CTA), como "Clica no link da bio" ou "Comenta abaixo".
4. Seleciona 10 a 15 hashtags relevantes, divididas entre hashtags de nicho, de marca e gerais.
5. Sugere uma ideia visual para a imagem ou vídeo que irá acompanhar este texto.

## Critérios de conclusão
- A legenda gerada deve ser apelativa, estruturada com emojis adequados e conter a CTA e as hashtags recomendadas.

Este ficheiro de configuração segue o formato canónico do Hermes Agent. O bloco YAML inicial (frontmatter) define os metadados da skill (como nome, autor e tags), enquanto as secções seguintes em Markdown instruem detalhadamente o agente sobre como estruturar a legenda perfeita para o Instagram, incluindo ganchos de atenção, chamadas para ação (CTA) e sugestões visuais.

Passo 3: Executar a Skill e Gerar o teu Primeiro Post

Com a skill devidamente criada e guardada no teu diretório de trabalho, podemos interagir com o Hermes Agent para gerar o conteúdo. Primeiro, listamos as skills para confirmar que foi detetada e, de seguida, executamos o chat interativo utilizando a skill.

# Listar as skills instaladas para confirmar a presença do instagram_generator
hermes skills list

# Iniciar o chat focado na skill de geração de Instagram
hermes chat -s instagram_generator

Ao executares o comando de chat com o parâmetro -s instagram_generator, o Hermes Agent inicia uma sessão focada exclusivamente nesta tarefa. Podes simplesmente escrever: "Quero criar um post sobre o lançamento das nossas novas sapatilhas de corrida ecológicas, feitas de plástico reciclado do oceano. O tom deve ser jovem e dinâmico." O agente irá aplicar todas as regras de escrita, ganchos e hashtags definidas na skill e devolver-te o post pronto a publicar.

Passo 4: Automação Avançada - Responder a Mensagens Directas (DMs)

Para além de gerar textos, podes integrar o Hermes Agent com scripts ou ferramentas de automação para monitorizar a tua caixa de entrada do Instagram. Sempre que um cliente enviar uma mensagem direta (DM) com dúvidas comuns, o teu sistema pode passar essa pergunta ao Hermes Agent para receber uma resposta natural e humanizada em segundos.

O exemplo abaixo mostra como um script simples em Python pode interagir com o Hermes Agent para processar e responder a uma dúvida de um cliente de forma automática, enviando a pergunta pelo terminal (stdin) e usando o modo de consulta única (--query-file), que executa o Hermes sem precisar de uma sessão interativa:

import subprocess

def responder_cliente(mensagem_cliente):
    # Usa o modo de consulta única do Hermes Agent: lê a pergunta do stdin
    # e executa a skill sem precisar de uma sessão de chat interativa
    comando = ["hermes", "chat", "-s", "instagram_generator", "--query-file", "-"]

    # Executa o comando no terminal do sistema e passa a pergunta pelo stdin
    resultado = subprocess.run(comando, input=mensagem_cliente, capture_output=True, text=True)

    if resultado.returncode == 0:
        return resultado.stdout.strip()
    else:
        return "Pedimos desculpa, mas estamos com dificuldades técnicas. Responderemos em breve!"

# Exemplo de teste de resposta automática
pergunta = "Olá! Vocês fazem envios para a Madeira e Açores?"
resposta_final = responder_cliente(pergunta)
print("Resposta gerada pelo Hermes Agent:")
print(resposta_final)

Este script em Python utiliza o módulo subprocess para chamar o Hermes Agent de forma programática, passando a dúvida do cliente pela entrada padrão (--query-file -) sem abrir uma sessão interativa. Para que a resposta seja útil a uma pergunta de atendimento (como envios ou horários), a skill instagram_generator deve incluir também as respostas às perguntas mais frequentes da tua marca — basta adicionar essa secção às Instruções da skill. A resposta gerada pode depois ser enviada de volta ao utilizador através da API do Instagram ou de plataformas de integração como o n8n ou o Make.
